电子政务申报门户

外国实体或私人利益基金会（PIF）必须首先将其私人利益基金会章程在巴拿马公共注册处正式登记，以确认其法律人格。随后，该实体需向巴拿马税务局（DGI）注册，以获取统一纳税人识别号（RUC）。具体程序如下：（i）指定一名常驻法律代表或税务代理人；（ii）提交经巴拿马公证的法定成立文件（基金会章程及规约）；（iii）提交形式02（运营通知/纳税人注册）文件，附上已登记的本地地址证明以及经认证的境外尽职调查文件（护照、董事/股东身份证明）；（iv）向当地市政当局申请业务许可证（运营通知），以开展本地经营活动。DGI将分配一个永久性的RUC，该号码为所有ITBMS、所得税及关税申报的法定税号。

税号代号与申请路径: Territorial_Scope — 外国实体或私人利益基金会（PIF）必须首先将其私人利益基金会章程在巴拿马公共注册处正式登记，以确认其法律人格。随后，该实体需向巴拿马税务局（DGI）注册，以获取统一纳税人识别号（RUC）。具体程序如下：（i）指定一名常驻法律代表或税务代理人；（ii）提交经巴拿马公证的法定成立文件（基金会章程及规约）；（iii）提交形式02（运营通知/纳税人注册）文件，附上已登记的本地地址证明以及经认证的境外尽职调查文件（护照、董事/股东身份证明）；（iv）向当地市政当局申请业务许可证（运营通知），以开展本地经营活动。DGI将分配一个永久性的RUC，该号码为所有ITBMS、所得税及关税申报的法定税号。

Territorial_Scope

支持身份选举表单

根据巴拿马法律，不存在美国式的勾选式或实体分类选择机制。根据1995年第25号法律，PIF被视为一种混合投资工具：来自巴拿马的收入在实体层面征税，而来自国外的收入则不在巴拿马领土管辖范围内（全球收入不适用；适用领土税）。可选择的选项包括：(i) 如果符合条件，可以选择采用简化纳税人制度；(ii) 注册为常规增值税纳税人；(iii) 根据非税收一般会计规则进行年度审计。根据OECD基础侵蚀规则，混合不匹配的选择方式并未被国内法规明确规定，但由于实行领土税制，这些选择方式在境内具有中立性。

强制登记营业额门槛 (Nexus)

B/. 36,000（巴拿马比索，与美元按1:1挂钩）的年度应税收入（来自国内销售）；营业额较高的企业必须注册为ITBMS纳税人，而规模较小的经营者可采用简化制度。

跨境出口 0% 零税率申报条件

向巴拿马境外客户出口商品，包括活性 Pharmaceutical 原料（APIs）（HS 第29/30章）的销售及离岸交付，只要货物实际离开巴拿马海关领土，且出口商持有有效的RUC，即可享受0%的ITBMS税率。零税率也适用于在巴拿马境外提供的服务、国际运输以及再出口业务。出口商须通过ANA海关的出口申报程序登记相应的出口业务；若向经认可的自由贸易区或科隆自由贸易区企业销售，可依据特殊制度认定为免税或再出口交易。

  • 通过SICE/海关系统提交的海关出口申报（出口申报），并附有指定的出口注册号码
  • 提单（或空运提单）证明从巴拿马启运
  • 商业发票和装箱单须明确引用精确的API商品代码及出口数量
  • 采购/销售合同或形式发票，用于支持出口价格
  • 汇入证明或银行电汇确认函，证明款项已由巴拿马银行机构收到出口收入

根据2019年DGI第201-0734号决议及后续修订，强制实施电子发票制度。从2022年起，根据纳税人规模不同分阶段实施该制度。经授权的纳税人必须通过DGI认可的软件或免费的Sede Electrónica发行平台来生成结构化发票（XML/PDF格式），并将电子文档近乎实时地传输给DGI以进行财政审核（获取接受/拒绝代码）。对于尚未执行该制度的企业来说，仍需使用经过批准的财政打印机。进口商品的增值税结算与ANA（国家海关局）的海关单一窗口系统（SICE）相结合进行，在最终放行之前，ITBMS已完成结算。

零费率声明需经过加强的DGI/ANA实时系统交叉验证（海关离境记录与发票及银行收据进行比对）。对国内消费进行虚假申报、少报发票金额或欺诈性零级定价，将导致按7%的税率加上每月复利计算的利息（目前约为每月0.833%）进行追溯增值税征收，并面临涉及税额20%至200%的罚款（《税收法》第700条和712条）。如果第三方故意不申报以操纵税收，则构成刑事责任。税务机关拥有6年的起诉期限，对于未提交申报表或存在欺诈行为的情况，这一期限可延长至10年。注意：巴拿马没有独立的外汇回流法规，因为巴波亚与美元价值相等，也没有任何上交义务；不过，DGI的审计实践中仍采用180天的商业基准来确认通过本地银行渠道获得的出口收益。

外汇管制与央行政策诊断

经常项目兑换自由度

巴拿马实行完全以美元为基础的货币体系；PAB可以按1:1的比例兑换成美元，并非浮动或受控制的货币。居民与非居民在经常账户兑换、贸易结算、服务费用、股息和特许权使用费方面的兑换都是无限制的。关于利润汇出方面：巴拿马实行领土所得税制度；那些仅来自外国收入的私人利益基金会则无需缴纳巴拿马所得税，对受益人的分配或补充福利也免于巴拿马税收。从巴拿马来源的利润中支付的股息，只需缴纳4.5%的预提股息税，该税率高于企业税率（对于来自巴拿马的收入，实际税率约为10%），但无需额外的外汇管制许可、中央银行授权或事先审批。在巴拿马持有美元、欧元或其他多币种账户没有限制，也没有任何限制用于贸易或财政目的的资金转移。注意：银行会对所有高风险制药API交易进行流动性风险验证，但这只是合规要求，而非兑换限制。

出口外汇强制结汇要求

不适用。巴拿马没有关于出口收入必须上缴的义务，也没有强制性的资金回流时间限制，更不存在对应收款项进行强制兑换的要求。药品原料批发出口商可以无限期地以美元（或任何允许使用的货币）在巴拿马或国外保留所有收入。没有规定的15/30/60/90天上交期限，也不存在将出口收入转换为巴波亚的义务。根据领土制度，如果API出口销售所得来自海外，且销售活动发生在境外或符合相关工业出口规定，则该收入不属于巴拿马的税收范围。不过，银行会根据SBP第7-2013号协议和2015年《反洗钱法》第23条要求，要求提供与每次出口应收款项相关的文件证明；实际合规要求是将商业发票、提单、分析证书以及SWIFT信用通知保存在账户文件中。

央行监管: 巴拿马共和国没有拥有货币发行或外汇管制权的传统中央银行。其官方货币为巴波亚（PAB），现在是一种纯粹的记账单位，与美元保持1:1的挂钩关系；自1904年起，美元便具有完全法定支付效力。主要的金融监管机构是巴拿马银行监管局（SBP），这是一个独立的国家机构，根据1970年第238号内阁法令设立，并于2008年第2号法律法令中进行了改革。巴拿马国家银行则作为共和国的财政代理机构，承担部分中央银行的行政职能，但不负责发行货币或运营外汇储备业务。经济与财政部负责协调宏观经济政策，而金融分析部门则负责监督反洗钱/反恐怖融资合规工作。巴拿马没有外汇管理机构、外汇管制委员会或资本流动许可机构。

离岸数字新锐银行 / EMI 白名单

Cross-border EMI / Fintech rails 适配度: High

可行性评级：针对指定的高风险药品原料药批发模式，评级为低至中等。巴拿马目前没有与欧盟PSD2框架相类似的专门电子货币机构（EMI）许可制度；支付服务提供商须依据2008年第2号法令及2018年第5号协议，获得巴拿马中央银行（SBP）批准的“支付公司”许可，且必须具备实质性的本地许可经营存在。境外数字EMI（如英国FCA许可的EMI、美国MSB或新加坡MPI）在法律上仅可为注册于巴拿马的特别目的公司（PIF）提供小额清算和费用垫付服务，且仅在其业务活动不构成在巴拿马境内的银行中介行为的前提下方可适用；未经许可的境外EMI若向巴拿马居民提供服务，将可能被认定为违反2008年第2号法令第4条所规定的未经授权的银行业务活动。实际上，若PIF使用境外EMI进行大规模原料药结算，该境外EMI的代理银行很可能会拒绝UBO透明的公司架构，导致以单据信用证结算的流程中断。建议架构：所有信用证及SWIFT MT103贸易清算流程均应通过获得SBP许可的一级银行进行锚定，仅将境外EMI用于非贸易类的日常运营费用（如差旅、快递、注册费）且单笔交易金额不得超过5000美元。

跨境清算通道与结算适配

用于接收资本的资金传输方式为SWIFT MT103格式，资金从创始人或投资者的境外账户流向位于巴拿马一级银行的美元结算账户。巴拿马没有强制性的用途代码分类要求（与严格外汇管制地区的BPM代码不同）；银行则依靠SWIFT字段70（汇款信息）以及相关的KYC文件来进行审核。对于股权类基金会资本，推荐的字段70内容应为：资本对私人利益基金的贡献 / 基金会注册号[XXXXX] / 非商业性 / 受赠人UBO[名称]。对于通过API交易产生的商业收款，描述内容应写为：用于偿还商业发票号[XXXX]的款项 / 药品API供应 / 贸易术语[CPT/CIP]，同时需提供相应的形式发票、商业发票和提单，由汇款方和接收方银行共同保存。收到款项后，巴拿马银行会对照UN/OFSI/EU/UK制裁名单对基金会、受赠人及汇款方进行审核，验证资金来源证明，并在同一营业日内将资金计入账户；金额超过25万美元时，通常需进行24-72小时的加强尽职调查，以等待文件确认。有三种法定/允许的清算方式可用于API批发结算。(i) 文件式信用证：根据ICC UCP 600标准发行SWIFT MT700格式的信用证，对于可转让或背对背的信用证则使用MT710/MT720格式；在到期时，信用证款项通过SWIFT MT754/MT202格式传输给确认银行，以美元形式通过纽约CHIPS/Fedwire通道进行结算；以欧元计价的信用证则通过法兰克福的TARGET2系统进行结算。通过CIPS进行CNY贷款资金转账。(ii) 向已批准的供应商进行的境外SWIFT MT103付款：巴拿马的本地ACH系统仅处理PAB/USD国内交易，不用于跨境贸易；所有外部美元转账必须通过美国代理银行进行。(iii) 根据ICC URDS 522规定的文件式集合交易方式，当交易方信用状况未经过验证时，这种方式更为适用。对于高风险药品支付交易，在执行前需先对供应商的MINSA许可证及产品相关的卫生注册进行确认。对于 HIGH_RISK_SPECIAL_LICENSE 类别，每日支付限额和第二人授权机制是标准要求；银行的 UAF 接口会监控每笔 MT103 交易的结构模式，以及出现文件不符情况的 STR/SAR 文件。普通的外汇远期合约（美元/欧元、美元/人民币、美元/英镑），期限为1至12个月；无需中央银行批准，因为美元/比索的汇率具有法律固定性，而比索为非实物交割的名义单位。针对特殊供应链货币（如印度卢比、印尼盾、越南盾、古巴比索）的不可交割远期合约，通过巴拿马银行位于纽约或伦敦的离岸财务部门进行交易；结算以美元为准价进行，因为巴波亚并非可离岸交易的货币。美元与欧元、美元与人民币之间的交叉货币互换（CCS），用于API批发业务的期限匹配的贸易融资负债。货币期权（针对欧元/美元及美元/人民币的看涨和看跌期权）用于对冲未来投标收入和供货合同应收账款，在固定人民币对美元汇率环境下避免溢价流失。在美元化的情况下，无需进行合成美元利率对冲；但可仍通过美元LIBOR/SOFR的远期利率协议来稳定LC贴现业务的融资成本。
