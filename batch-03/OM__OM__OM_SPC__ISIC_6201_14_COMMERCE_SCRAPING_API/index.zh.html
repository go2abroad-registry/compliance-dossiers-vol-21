法定实缴资本与验资锁资账户流程 强制验资锁定

单人公司没有法定最低资本要求；在并购过程中，认购股本可以自由确定。注册处不需要任何托管资金或银行预付款项；注册资本必须在商业登记证颁发后支付，并需记录在阿曼银行的公司账户中。

注资与解冻路径: 办公场所需取得ROP民防部门及市政商业装修/建筑许可的消防安全证明；若公司日后雇佣员工，则需符合卫生部的职业健康许可以及依据阿曼劳动法制定的基本工作场所安全政策。

实缴资本规则: 单人公司没有法定最低资本要求；在并购过程中，认购股本可以自由确定。注册处不需要任何托管资金或银行预付款项；注册资本必须在商业登记证颁发后支付，并需记录在阿曼银行的公司账户中。

官方税号申请基础设施

主管税务局

阿曼税务局（OTA）——作为阿曼苏丹国的统一国家税务机构，是财政部税务事务总办公室的继承者。官方电子服务及税号/增值税门户网站为：https://taxoman.gov.om（涉及申报、零税率安排及退款相关事务）；企业注册则通过商业、工业与投资促进部“Invest Easy”门户网站进行，网址为：https://investeasy.gov.om；海关出口清关则通过阿曼皇家警察海关“Bayan”平台完成。

根据阿曼商业公司法（皇家法令第18/2019号），通过摩卡投资易（MoCIIP）投资门户设立100%外方持股的单人公司（SPC），无需缴纳法定最低注册资本。由此获得的商业注册号（CR）为统一国家识别码。SPC随后须完成以下事项：（1）取得市政营业执照；（2）向阿曼税务管理局（OTA）申报企业所得税，获取统一纳税人识别号（TIN）和企业税卡；（3）在可税销售额超过38,500阿曼里亚尔（OMR）后30日内，于taxoman.gov.om平台注册增值税，或在可税销售额或支出超过19,250阿曼里亚尔（OMR）时自愿注册，通常在5个工作日内完成TIN发放；（4）以SPC自身的CR/TIN名称开设并维持一个阿曼结算银行账户，该账户是出口收入汇款证书（Inward Remittance Certificate）的必要条件；（5）如存在以商品为基础的API/硬件流动，须在“Bayan”海关平台注册为出口商；（6）对任何符合条件的自由区设立进行TIN更新。外国股东无需阿曼本地合伙人、最低注册资本或先前的税务清关。

经济实质审查范围: 阿曼经济实体规定（根据第37/2022号皇家法令及相关实施决定）适用于银行、保险、基金管理、总部运营和控股公司等指定业务。网络抓取和API网关SPC并不自动属于这些指定业务范畴；然而，该SPC必须证明具有真正的运营实体特征（实体/市场存在、在阿曼的决策活动、积极就业情况、服务基础设施），以支持其作为常设机构的地位、符合条约要求，并避免被重新分类为空壳公司或外国主提供方的永久机构。

致命合规红线与董事个人责任

逃税

法定制裁: 民事处罚金额为避免的税款加上每月3%的罚款（上限为100%）；根据阿曼《刑法税法修正案》（皇家法令第9/2017号），最高可处以25,000阿曼里亚尔的刑事罚款，高管人员还可能被判处监禁。

空壳公司 / 人为规避

法定制裁: 将所有来自阿曼的收入重新归类为与母公司的常设机构有效关联的收入；拒绝扣除各项费用及条约优惠；按15%的税率征税，并加收最高达额外税负100%的惩罚性附加税。

董事个人责任:
反洗钱/制裁违规

法定制裁: 根据反洗钱法（皇家法令第30/2016号，经修订），企业可被处以最高不超过20,000利比亚第纳尔的罚款；相关责任人可能被判处最高7年的监禁；并可能被下达没收其利润及董事个人财产的资产冻结令。

董事个人责任:
转让定价不合规

法定制裁: 利润向上调整至公允水平，对未足额缴纳税款部分计收利息，并处以10%至25%的申报错误罚款；未能保持（或在60天内提供）转让定价（TP）文件证据，将自动触发5000利里（OMR）的罚款。

董事个人责任

法定制裁: 根据阿曼《商业公司法》和《税收征收法》，公司面纱被突破后：董事需对未缴纳的税款、个人银行/证券及不动产冻结命令承担责任；对于累计超过5,000阿曼里亚尔的税款债务，财政部会发布旅行禁令；对于欺诈性申报行为，可处以最高3年的刑事监禁。
