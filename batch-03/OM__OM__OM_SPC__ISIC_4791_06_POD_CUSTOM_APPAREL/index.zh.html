官方税号申请基础设施

主管税务局

阿曼税务局（OTA）——根据第29/2020号皇家法令设立的国家税收机构，是税务总秘书处后的继承机构；官方电子服务与申报平台位于www.taxoman.om，相关指导信息可查阅ota.gov.om。

电子政务申报门户

对于由外国自然人或法人全资拥有的单人公司（SPC）：（1）依据《商业公司法》（皇家法令第18/2019号）设立SPC，并向商业、工业与投资促进部（MOCIIP）申请商业注册（CR）；（2）在获得商业注册后3个月内，根据《所得税法》执行条例（皇家法令第9/2017号，经皇家法令第80/2022号修订）向税务总局（OTA）提交所得税登记，附上商业注册文件、公司章程（MOA/AOA）、董事会及股东决议、外国股东护照复印件或公司注册证明、注册地址证明以及银行账户确认文件；税务总局将核发税务识别号码（TIN）及注册证书；（3）一旦年度应税供应额和进口额超过38,000OMR，须依据皇家法令第33/2019号（增值税法）单独注册增值税；（4）向皇家阿曼警察海关在BAYAN电子海关系统中进行注册，以获取POD服装进出口的海关申报号码。

跨境出口 0% 零税率申报条件

根据《统一增值税协议》第30条以及阿曼增值税执行条例第30至35条，当商品出口到海合会成员国以外的地区时，POD定制服装的供应属于零税率商品。标题和风险必须转移给阿曼境外的购买方，且货物必须在供应日期后90天内实际离开阿曼（可延长至90天）。与出口直接相关的出口服务（如包装、物流处理、用于出口的国际运输等）可能获得零关税待遇或不属于适用范围。出口商必须持有有效的海关出口申报单（BAYAN e-SAD）、商业发票、INCO合同（DAP/FOB）、运输运单，以及通过阿曼授权的PSP或合作银行收到的支付凭证（如Stripe/PayPal结算、SWIFT MT103或进款证明）。以及一份列出所有免税出口商品的增值税申报表。对于非居民电子商务主体进行的出口业务，必须确保代理/主体的文件链完整，以避免反向征税或遗漏出口税的风险。

  • 海关出口申报（巴亚单一行政文件/电子出口申报）并具有OTA认可的出口状态
  • 商业发票及符合增值税规定的税务发票，显示0%税率和出口参考编号
  • 提单（海运）或空运提单/快递提单（空运），证明货物自阿曼启运并抵达出口目的地
  • 装箱单及含HS编码的INCOTERMS合同，用于目的港服装及配饰
  • 入账证明 / SWIFT MT103 / 经许可的支付服务提供商（Stripe/PayPal）结算报告，显示出口收入已存入阿曼银行账户
  • 银行对账单及结汇记录需符合180天汇回额度内的发票金额

目前，阿曼并未实施强制性的实时财务结算或税务发票数字盖章制度；也没有像沙特ZATCA第二阶段那样有效的OTA API结算机制。OTA电子服务平台支持电子增值税登记、CSV/XML申报提交、电子通知以及纳税人账户管理；公共部门的电子发票业务则通过ePay/电子政务平台进行推广。私营部门的POD零售商必须在商品交付后28天内出具符合增值税要求的税务发票，该发票必须包含《增值税法》和相关执行法规中规定的所有字段，同时还需注明0%的出口税率及出口参考信息。所有发票文件、BAYAN海关申报单以及PSP/银行结算记录都必须保存至少10年，以便进行OTA审计检查。

OTA审计程序会将BAYAN海关出口申报与零税率增值税记录、税务发票、PSP结算账簿（Stripe/PayPal）以及银行对账单进行核对。如果零税率申报不符合90天实物出口要求、缺少相关文件，或表明存在来回运输或虚报费用情况，则该申报将被撤销。追溯机制如下：出口费用需按5%的增值税率重新计算，相关的输入增值税抵扣则被取消；已支付的退款（包括根据《增值税法》第43条规定的及时出口商退款）也将作为超额税款被收回，同时需支付10%的法定罚款。若行为重复或欺诈行为，将面临每月高达7%的滞纳金（最高不超过应缴税额的100%），根据《税务程序法》（皇家法令23/2020）规定，可能面临高达200%的逃税罚款，还可能面临最高3年的监禁及20,000阿曼里亚尔的罚款，且会被从OTA快速退款可信纳税人通道中剔除。一般评估期限为相关税务期结束后的5年，若存在欺诈或故意违规行为，该期限可延长；出口企业有责任证明实际进行了实物出口。

外汇管制与央行政策诊断

经常项目兑换自由度

经常账户：完全可兑换，用于货物和服务贸易；对于真实存在的本地采购（POD）贸易付款、平台结算转账及供应商付款，无需事先获得中央银行（CBO）批准。资本账户：根据2019年第50号皇家法令（外商资本投资法）实行宽松政策；允许完全的外方持股，且资本金注入、贷款偿还及利润汇回均无需外汇许可证。实践中，银行对等值5万美元以上的境外股权汇款实施加强的文件审查，对于汇出股息或利润，要求提供经审计的财务报表、来自阿曼税务机构的税务清关证明，并征收10%的预提所得税（除非根据适用的避免双重征税协定予以减免）。阿曼里亚尔（OMR）与美元挂钩，汇率为1 OMR = 2.6008 USD，浮动幅度为±0.02%，几乎消除了OMR/USD的兑换风险。净可兑换门槛：货物和服务贸易方面门槛较低；利润汇回方面门槛中等，主要由于需要提供文件证明及预提所得税（WHT）要求。

出口外汇强制结汇要求

没有强制汇回要求。CBO不规定在线零售销售产生的出口收入应按何种转换比例或汇回期限进行处理；出口商和电子商务商家可以合法地将全部外汇收入（美元、欧元、英镑）保留在阿曼的外汇账户中，或者自愿进行兑换。不过，由CBO监管的银行要求，阿曼居民实体的商业收入必须通过持牌阿曼银行进行处理，以便进行统计报告和反洗钱审查；大多数银行都设定了在发票或发货日期后180天内汇回的内部标准，且收入必须与相关的海关申报文件或平台支付报告保持一致。

央行监管: 阿曼中央银行（CBO）——阿曼中央银行；外汇业务还受到《外汇业务监管法》（皇家法令第37/2003号）及经修订的CBO公告BM 1024的规范。

跨境清算通道与结算适配

合规路由：从境外股东银行通过SWIFT MT103汇款至SPC在获准银行开设的OMR账户，付款用途代码为“视为股权投入/股份认购——外国资本投资法（第50/2019号法规）”。收款银行在入账前需完成以下验证文件的审核：（i）商业注册文件，包含SPC的相关信息；（ii）公司章程，反映已授权或实缴资本（SPC无需最低注册资本；但银行通常要求提供至少OMR 1,000至3,000的营运资金证明）；（iii）董事会决议，批准该笔汇款；（iv）资金来源声明及最终受益所有人（UBO）确认表；（v）向阿曼税务局提交的注册证明文件（如涉及增值税则需提供）。资金到账后，通过CBO的实时清算系统（RTGS）处理，资金在T+0或T+1日内可使用。对于等值超过5万美元的款项，银行将执行额外尽职调查，若该笔汇款被认定为公司间债务而非股权投入，则可能要求提供经公证的贷款协议。用于POD供应商付款的标准清算渠道是通过CBO许可的银行进行的SWIFT MT103交易；典型的美元支付方式是通过代理银行进行（如摩根大通、花旗银行、汇丰银行美国或英国分行），结算时间为1至3个营业日。对于金额较小的定期POD付款（通常每次交易不超过10,000美元），可以使用阿曼的授权货币兑换机构进行OMR/美元支付，但每个实体每天的支付上限为8,000美元。商业信用证（即即期或远期信用证）也是可行的，但对于低价值的POD零售采购来说，其使用规模可能过于庞大；建议仅在批量空白服装进口订单超过100,000美元时才使用，以降低货物未送达的风险。对外付款时，需要提供供应商发票、订单证明，以及适用的海关申报文件；银行会将所有收款人名称与OFAC/欧盟/联合国制裁名单进行比对。OMR/USD远期交割合约（可从所有一级奥mani银行获得；由于汇率固定为2.6008，点差极小）。OMR/GBP 和 OMR/EUR 的交割远期（适用于英国/欧盟交货地供应商付款；通常期限最长为12个月，需提供贸易单据）。跨境货币互换（第纳尔对美元、欧元或英镑）用于集团内部融资结构；需经CBO许可银行审批，并提供相应的基础风险敞口证明。由穆斯卡特银行、汇丰银行（阿曼）和索哈国际提供的主要货币对（欧元/美元、英镑/美元）的场外外汇期权，用于对账款的汇率风险对冲，需提供贸易文件作为依据。鉴于美元汇率的固定性，对于OMR交易来说，不需要也不存在价格合理的NDF（不可交付远期合约）。理论上，NDF可以在境外进行交易，但建议不要采用这种方式，因为这会给居民实体带来CBO监管方面的不确定性。

电商与网关结算适配度: 采用有条件解决方案，属于低到中等级别。海外数字电子支付服务商（如Wise、Airwallex、Payoneer、Stripe等类似Stripe Treasury的机构）并未被CBO批准为阿曼的银行或支付服务提供商；将其作为企业主账户使用会带来监管和税务方面的问题（因为应收账款最终必须存入CBO批准的账户才能进行收入确认）。可行的方案包括：(i) 仅将PayPal/Payoneer用于应收账款收集，定期（如每周）将款项转入阿曼企业账户；(ii) 海外电子支付服务商可仅作为Stripe/PayPal付款的结算渠道使用，前提是所有相关资金已核对并汇回国内；(iii) 对于海外电子支付服务商的借款或存款行为，无需获得阿曼的监管批准。另一种完全合规的方案是：在马斯喀特银行或HSBC Oman开设阿曼SPC账户，设立一个美元外币子账户，然后利用CBO批准的汇款机构将美元资金支付给没有使用电子支付服务的海外POD印刷供应商。

转让定价与经济实质

主文档/本地文档门槛: 如果年度相关方控制交易总额达到1,000,000奥米尔，则必须遵守本地文件要求；当合并集团营业额或相关方交易额超过50,000,000奥米尔时，或根据OTA的要求，应编制一份集团主文件。

经济实质审查范围: 阿曼没有像其他海湾国家那样拥有独立的《经济实体法规》法律。不过，阿曼的税法适用以实体为对象的反避税规定、税收条约中的实际所有者条件，以及需要设立实体办公室、当地决策者、员工和实际经济活动的自由区/特殊经济区许可要求。没有商业实体的控股公司可能会被重新认定，从而失去条约或优惠待遇，并会被按视为应税实体进行征税。

致命合规红线与董事个人责任

逃税 / 虚报欺诈性少报

法定制裁: 重新评估全部逃税金额，通常包括相当于未足额征收税款200%的逃税罚款，以及最高可达五年监禁的刑事处罚。

董事个人责任: 签署虚假报税文件的董事、经理及法定代表人，应就未缴税款及罚款承担连带责任；他们可能面临旅行禁令、资产冻结、刑事定罪及监禁。
空壳公司 / 虚假实质

法定制裁: 对实体或交易的重新定性，拒绝税收协定和税收优惠豁免，按视为收入全额适用公司税率，并处以最高达所征税款100%的罚款。

董事个人责任: 在阿曼商法中，揭开公司面纱可能使股东和董事对公司未缴税款和债务承担个人责任；旅行禁令和资格取消令也可能被适用。
反洗钱/洗钱

法定制裁: 在阿曼反洗钱框架下，对洗钱所得实施没收，可处以重大反洗钱罚款，并处以最高七年监禁；对未申报的资金还将适用逃税处罚。

董事个人责任: 拥有实际或推定知情的董事及合规官将面临个人刑事责任、资产追缴行动、旅行限制以及被禁止担任公司管理人员的处罚。
转让定价不合规

法定制裁: 关联交易价格调整、额外企业所得税、迟缴利息、未提供文件的行政罚款，以及故意虚报价格被认定为逃税可能面临的刑事责任。

董事个人责任: 批准非公允交易的董事可能需就额外税款、罚款及利息承担个人责任；严重违规行为可能构成欺诈，并导致个人资产被查封。
迟报 / 未缴纳企业所得税

法定制裁: 每月申报附加费、逾期付款利息、行政罚款、对银行账户及资产的强制执行，以及持续违约可能面临的刑事处罚。

董事个人责任: 阿曼的法律代表或常驻经理为指定申报人；若未申报且未缴款，该个人将面临个人追偿、旅行禁令以及民事责任，而不仅仅是公司层面的处罚。
