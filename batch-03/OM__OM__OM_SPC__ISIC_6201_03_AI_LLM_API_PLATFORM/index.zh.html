法定实缴资本与验资锁资账户流程 免验资锁资账户

根据2019年第18号皇家法令，单一个人公司无需缴纳法定最低注册资本；股本在公司章程中已明确规定，必须在成立时全部认购并全额支付。同时，需提供银行证明，证明资本已存入公司银行账户，该证明须在商业注册证书发放前提交。

注资与解冻路径: 消防安全证书由民防与急救局（CDAA）出具，经对注册办公地址进行检查，涵盖灭火器、烟雾探测、紧急疏散通道以及IT设备电气负载的安全性；马斯喀特市议会出具的结构荷载检查和建筑安全许可，确认该场所适合用作办公场所；根据《劳动法》（皇家法令第35/2003号）出具的职业安全许可，确认工作场所无危险性，配备急救措施，并且IT服务器室具备足够的通风条件；由于该场所按ISIC 6201（以办公为基础）分类，无需取得工业用地分区许可。

实缴资本规则: 根据2019年第18号皇家法令，单一个人公司无需缴纳法定最低注册资本；股本在公司章程中已明确规定，必须在成立时全部认购并全额支付。同时，需提供银行证明，证明资本已存入公司银行账户，该证明须在商业注册证书发放前提交。

外汇管制与央行政策诊断

经常项目兑换自由度

阿曼里亚尔的汇率固定为1阿曼里亚尔等于2.6008美元。根据阿曼在国际货币基金组织章程第八条中的义务，该货币可以在经常账户交易中完全兑换。资本账户流动则较为自由：由外国完全拥有的单个人公司可以接受股权注入、提取公司间贷款，并在没有中央银行事先批准的情况下向海外支付股息，只要支付银行能够获得相关的企业文件即可。利润回流的限制仅涉及书面文件要求（如有效的商业注册证明、个人与法人身份声明、银行授权文件、公司章程，以及当单个人公司的收入超过阿曼税务局申报阈值时所需的税务申报证明）。不存在回流配额、汇率稳定费，也不存在对AI/LLM API服务出口业务的特殊转换率。

出口外汇强制结汇要求

阿曼不要求必须上交出口收入，也不设定法定的最低兑换比例。阿曼公司可以将其来自Stripe/USDC的出口收入保留在自己账户中，使用获得CBO许可的银行以美元或任何可兑换外币形式存储；转换为阿曼里亚尔则属于自愿且商业行为。相关约束条件包括：(i) 同时提供与AI/LLM API出口发票相关的文件证明；(ii) 将出口收入存入以该公司名义在阿曼银行开立的账户中；以及(iii) 将大额跨境收入纳入CBO国际收支统计报表中。对于ISIC 6201服务出口收入而言，没有强制性的交出时间要求。

央行监管: 阿曼中央银行（CBO），马斯喀特——作为阿曼苏丹国唯一的货币发行机构、外汇监管机构和支付系统监管机构，依据《银行业法》（皇家法令第114/2000号，经修订）、《外商投资资本法》（皇家法令第50/2019号）以及《商业公司法》（皇家法令第18/2019号，经修订）行使职权。阿曼中央银行运营全国实时全额结算系统（MIR），并规定所有获准银行在跨境汇款中须遵循的国际收支统计报告框架。

股权注入：外国母公司通过SWIFT MT103信用转账向指定阿曼银行的SPC美元运营账户汇款，附言为“股本认购——[CR编号]”，该银行将此交易归入CBO对外贸易平衡统计分类中的直接投资股权项目。集团内部贷款提款：通过SWIFT MT103（或用于非本地账户的MT202）汇款，附言为“集团内部贷款——[贷款协议日期]”，并附有已签署的信贷协议及SPC董事会决议。收款银行将核实CR、账户授权、最终受益所有人（UBO）披露信息，以及超过CBO统计报告阈值的金额的预期价值通知。运营流动性收入使用相同的入账路径：Stripe的付款通过SWIFT/SEPA从Stripe的银行合作伙伴或经批准的商户记录商（Paddle或FastSpring）直接汇入美元集中账户；USDC款项则通过经CMA/CBO许可的虚拟支付服务提供商（VASP）或经许可的阿曼银行场外交易柜台进行兑换，并在48小时内汇入同一美元账户。用于交易和运营支出的主要清算渠道：通过银行在线审批系统执行的SWIFT MT103客户信用支付，涉及云计算、GPU托管、LLM API供应商费用、许可费用以及公司间结算；每笔借记款项均附有供应商发票和SPC董事会的支付指令作为凭证。对于需要运输和海关文件硬件采购（如GPU服务器、存储阵列），建议采用书面文件记录和不可撤销的商业信用证（UCP600）进行支付。国内OMR支出——包括工资、租金、法定社会保障费、增值税及企业税分期付款——则通过CBO的MIR RTGS和国家工资档案系统进行结算。财政控制措施包括：对每个供应商的月度支付上限限制、由主管/经理双重审批，以及禁止使用指向加密货币钱包地址的转账方式。由持牌阿曼银行提供的即期远期和即期延期远期外汇交易，期限最长为12个月，须有经证实的贸易或资产负债表头寸作为支持，且不得存在投机性头寸。外汇远期互换（即期/远期滚动交易及T+0/下一日交易）用于满足OMR营运资金需求，同时保持美元负债的对齐。在银行交易柜台进行的跨境即期汇率兑换（美元、欧元、英镑、鲁比），用于发票结算、集团间净额结算及供应商付款。允许基于有据可查的敞口情况对奥曼里亚第/美元外汇期权进行标准化交易；鉴于SPC采用固定的2.6008美元汇率，不建议使用此类期权。OMR市场目前没有活跃的非交割远期（NDF）交易；符合条件的对冲交易必须在境内以交割合约形式执行。允许以OMR/USD的利率互换或交叉货币互换用于期限债务风险对冲，但必须通过境内银行的财务部门进行操作。
