Master / Local File threshold: Oman legt keinen minimalen Schwellenwert für öffentliche Lokale Dateien/Basisdateien fest. Als Sicherheitsschwellenwert sollte eine zeitgleich erstellte Lokale Datei vorhanden sein, bei der die gesamten grenzüberschreitenden Transaktionen mit beteiligten Parteien im Steuertermin einen Wert von mehr als 500.000 OMR erreichen; außerdem sollte eine Basisdatei vorliegen, bei der das multinationale Unternehmen einen konsolidierten Umsatz von mehr als 20.000.000 OMR aufweist.
