Registered Agent & Physical Address Lizenzierter Registrierungsagent zwingend

Das neuseeländische Recht erlaubt es, dass eine registrierte Niederlassung an der Adresse eines professionellen Unternehmensdienstleisters angesiedelt ist – es ist nicht erforderlich, dass das Unternehmen eigene Räumlichkeiten besitzt. Für eine SaaS-Organisation im Bereich VPN/Netzwerksicherheit sind jedoch höhere Anforderungen an die steuerlichen und bankrechtlichen Vorgaben: Die Inland Revenue verlangt eine gültige Geschäftadresse und kann Bestimmungen ablehnen, die ausschließlich auf einer kommerziellen Postbox beruhen. Banken in Neuseeland sowie Drittanbieter für Zahlungsverarbeitung lehnen in der Regel eine virtuelle Niederlassung für Kundenüberwachungspflichten ab, es sei denn, sie wird mit einer physischen Geschäftstätigkeit, einer lokalen Leitung oder einer operativen Präsenz versehen. Daher ist eine virtuelle Niederlassung zwar für die Gründung und die rechtlichen Korrespondenz geeignet, aber nicht ausreichend für die Eröffnung von Bankkonten oder die Einrichtung von Handelsbetrieben. Sie sollte daher mit einer physischen Serviceadresse oder einem Co-Working-Space kombiniert werden.
