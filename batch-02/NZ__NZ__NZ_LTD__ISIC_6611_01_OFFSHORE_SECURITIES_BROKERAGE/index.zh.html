外汇管制自由度 新西兰实行自由浮动货币制度，在宽松的监管框架下，货币交易和资本账户交易均可自由兑换。新西兰储备银行不实施外汇管制，新西兰元可完全用于贸易、直接投资、金融交易及利润汇出。出口收入无需上交，资本流入或流出无需中央银行审批，股息、股本或清算收益的回流也不受行政限制。主要的监管限制并非外汇管制，而是审慎监管、2009年《反洗钱与打击恐怖主义融资法》规定的反洗钱义务，以及2005年《海外投资法》中关于外国持有敏感土地或商业资产的要求。拥有非居民股东的证券经纪公司必须证明其自身并不持有此类敏感资产，并通过结算银行提交准确的国际收支/国际交易报告系统申报表。只有当银行认为高风险金融服务实体存在较高的反洗钱/恐怖融资风险时，才可能出现汇款方面的限制；在这种情况下，必须提供加强版的尽职调查资料及资金来源证明。外国投资者可以持有新西兰元或离岸外币账户，并可通过可交易的远期合约和互换市场进行自由对冲，但需遵守常见的市场记录和信用限额要求。总体而言，新西兰的监管制度属于无外汇管制、开放资本账户的模式，仅存在以合规为中心的约束条件。

董事会首期决议范本 (Pro-Forma First Board Resolution)
NZ_LTD首轮董事会决议

以下签名人作为NZ_LTD的正式董事，根据1993年《公司法》及公司章程通过书面决议，决定并记录如下：

1. 公司章程与注册。公司注册申请中附上的公司章程被采纳为公司的章程，符合1993年《公司法》第122条的规定。董事有权提交注册申请，支付规定的公司办公室费用，并对公司章程进行必要的修改，以获得新西兰公司办公室的注册许可。

2. 股本与分配。公司的法定股本按注册申请中规定的数量及面值设立。初始股份按董事根据1993年《公司法》第123-127条确定的条件分配给申请中指定的认购人。对价可以是现金、财产或服务，股份也可按董事会决定以全额支付或部分支付的方式发行。董事会确认，成立公司无需支付法定最低注册资本，且公司办公室也不要求设立托管账户。

3. 注册办事处。公司的注册办事处位于注册申请中指定的街道地址，即新西兰的实体地址。董事有权根据1993年《公司法》第184条提交注册办事处通知。注册办事处应在正常营业时间接受文件送达，也是公司法定登记册的存放地址。

4. 董事与高级管理人员的任命。同意表格上列出的人员被任命为公司的董事。每位董事均同意履行职责，并提供了所需的法定声明和身份文件。如适用，董事会可任命决议中指定的人员担任公司秘书，除非董事会另有决定。所有董事都应本着诚信原则，按照1993年《公司法》和2013年《金融市场行为法》的要求，谨慎、勤勉地行使权力和职责。

外汇管制与央行政策诊断

经常项目兑换自由度

新西兰实行自由浮动货币制度，在宽松的监管框架下，货币交易和资本账户交易均可自由兑换。新西兰储备银行不实施外汇管制，新西兰元可完全用于贸易、直接投资、金融交易及利润汇出。出口收入无需上交，资本流入或流出无需中央银行审批，股息、股本或清算收益的回流也不受行政限制。主要的监管限制并非外汇管制，而是审慎监管、2009年《反洗钱与打击恐怖主义融资法》规定的反洗钱义务，以及2005年《海外投资法》中关于外国持有敏感土地或商业资产的要求。拥有非居民股东的证券经纪公司必须证明其自身并不持有此类敏感资产，并通过结算银行提交准确的国际收支/国际交易报告系统申报表。只有当银行认为高风险金融服务实体存在较高的反洗钱/恐怖融资风险时，才可能出现汇款方面的限制；在这种情况下，必须提供加强版的尽职调查资料及资金来源证明。外国投资者可以持有新西兰元或离岸外币账户，并可通过可交易的远期合约和互换市场进行自由对冲，但需遵守常见的市场记录和信用限额要求。总体而言，新西兰的监管制度属于无外汇管制、开放资本账户的模式，仅存在以合规为中心的约束条件。

出口外汇强制结汇要求

新西兰法律中不存在法定退付机制。出口商保留对外币收入的完整所有权，可以将所得资金留在新西兰或海外外币账户中，且没有强制性的兑换比例或时间要求。所有海外收入只需通过国际交易报告系统进行国际收支统计报告即可。实际的银行要求是向结算银行提供相关的出口/交易文件，以支持SWIFT目的代码并便于交易监控。

跨境清算通道与结算适配

合规的境内资本注入必须通过SWIFT MT103/MT202电汇方式办理，并明确注明“向新西兰有限公司进行股权出资以实现资本化”，其经济用途代码须与新西兰储备银行国际交易报告系统中记录的资本汇入相匹配。收款银行将出具外国投资流入申报文件，资金结算后，由法定审计师出具证明文件，确认资金已划入新西兰元资本保证金账户。无需中央银行事前批准，但银行将要求提供基础法律协议、股东会决议以及境外银行资金来源证明，以确定适当的国际收支分类。最终的资本核实还应包含一条审计追溯路径，将公司注册处登记的资本账户与具体的境外汇入资金相连接，并包括所有货币兑换确认凭证。在贸易结算方面，主要清算渠道为SWIFT MT103或MT202，用于账期付款，所有出账消息均需包含完整的交易对手标识及准确的目的代码。对于高价值实物商品结算或交易对手要求银行保函的情形，建议由结算银行根据UCP600条款签发商业信用证。在交易双方信任程度适中的情况下，可采用URC522规定的单据托收方式，前提是基础运输单据能够提供风险隔离。客户资金向境外经纪商或流动性提供方的支付，必须通过独立的客户资金账户进行单独追踪，并通过SWIFT GPI完成，且必须严格核实收款方信息，不得与自有资本混合使用。所有对外转账均需附带基础贸易协议、发票、外汇交易凭证以及受益所有权确认文件，相关记录须至少保存五年。以新西兰银行为交易对手方，并依据ISDA协议或自有资金抵押安排开立的纽元对美元、纽元对欧元、纽元对英镑、纽元对澳元及纽元对日元的远期外汇合约，期限最长可达24个月。关于人民币、印度卢比和印尼盾等受限或离岸货币的不可交割远期合约，仅当相关风险敞口属于真实的商业交易结算，且此类不可交割远期合约通过许可的一级银行或授权衍生品交易商进行交易时，才予以办理。仅用于将长期外币资产与因客户隔离信托余额产生的外币负债对齐的跨境货币互换，须符合FMA的行为指导及董事会批准的财务政策。用于对冲或有经纪结算风险的外汇期权，仅限于期限最长为十二个月的现金结算合约，并且在任何客户资金的投机性使用之前必须平仓。
