外汇管制自由度 新西兰实行自由浮动汇率制度，没有关于外汇控制的全面法律规范。新西兰储备银行对常规经常账户或资本账户交易无需事先批准，新西兰元也可以完全兑换，无需强制性的返还要求。出口商可以无限期保留外币收据，法律也不规定任何兑换比例。利润汇出、股息分配和贷款偿还均被允许，但需遵守标准的税收预扣和企业文件要求。非居民可以拥有新西兰有限公司的股份，而无代码网站构建器的业务范围也不需要遵循特定行业的外国直接投资审查规定。因此，实际限制并非外汇控制，而是银行尽职调查要求，因为银行必须独立核实实际所有权、资金来源及合法业务目的。新西兰储备银行注重审慎监管和系统性稳定，将货币自由交易权留给市场参与者。对于普通的SaaS企业来说，进行财务操作无需获得中央银行的特殊许可或外汇批准。

[公司名称]有限公司董事会第一次会议于[日期]根据《1993年新西兰公司法》通过决议。主席确认，法定人数已到齐，且所有法律法和宪法规定的通知均已送达或处理完毕。经审议后，董事会一致通过了以下决议：1. 股本认购与分配。决定董事会接受会员名册上所列会员的认购；公司按董事会确定的发行价格向每位会员分配[数量]股普通股；对价以现金、财产或经董事会批准的服务形式收取。应开设股东名册和股份登记册；且股票证书应由两名董事签字发行。进一步决议指出，所有认购资金应全额入账，不得以折扣价发行任何股票。2. 注册办事处确认。决定公司的注册办事处设在新西兰的[实际地址]，并将该地址作为注册办事处和服务地址向公司注册处备案。进一步决定：除非经董事会决议并根据《公司法》第201至203条通知登记处，否则对注册办事处任何变更均不生效。3. 银行授权。决定任命[银行名称]为公司的主银行家；要求该银行以公司名义开立一个商业活期账户；该账户授权需由两名董事签字，或一名董事与企业秘书共同签字；此外还需办理电子银行授权、直接扣款等相关手续。电汇和付款协议应由相同的签署人执行。进一步决定，董事有权协商银行条款，并提供银行要求的赔偿承诺。4. 法定职位的任命。决定任命[董事A姓名]和[董事B姓名]为公司的首任董事；任命[董事A姓名]为总经理；任命[某官员姓名]为公司秘书；并聘请一名独立会计师来维护会计记录。进一步确认，董事们保证至少一名董事将按照《公司法》第151条的规定，通常居住在新西兰。5. 治理与持续授权。决定采纳附在注册申请中的宪法；公司采用3月31日结束的财政年度；授权董事和公司秘书签署所有申请、通知、税务登记文件。实施上述决议所需的银行授权和合同。进一步决定，这些决议在经后续董事会决议修改或撤销之前，仍具有完全效力。

  • 提单、主运单或house运单显示出发港口或机场为新西兰，且目的地为海外

新西兰不实施强制性的实时财务清算、持续交易控制、政府API授权或反欺诈数字印章制度。电子发票制度属于自愿性措施，通过新西兰PEPPOL网络进行运作。税务局接受电子记录和税务发票，但发票必须包含1985年《商品和服务税法》及1994年《税务管理法》所规定的法定内容：供应商法定名称和IRD号码、开具日期、供应描述、不含税金额，以及GST金额或明确说明价格已包含GST的声明、总应付款额，以及适用的税务发票格式要求。开具GST发票时无需事先进行预清关手续。

外汇管制与央行政策诊断

经常项目兑换自由度

新西兰实行自由浮动汇率制度，没有关于外汇控制的全面法律规范。新西兰储备银行对常规经常账户或资本账户交易无需事先批准，新西兰元也可以完全兑换，无需强制性的返还要求。出口商可以无限期保留外币收据，法律也不规定任何兑换比例。利润汇出、股息分配和贷款偿还均被允许，但需遵守标准的税收预扣和企业文件要求。非居民可以拥有新西兰有限公司的股份，而无代码网站构建器的业务范围也不需要遵循特定行业的外国直接投资审查规定。因此，实际限制并非外汇控制，而是银行尽职调查要求，因为银行必须独立核实实际所有权、资金来源及合法业务目的。新西兰储备银行注重审慎监管和系统性稳定，将货币自由交易权留给市场参与者。对于普通的SaaS企业来说，进行财务操作无需获得中央银行的特殊许可或外汇批准。

出口外汇强制结汇要求

在新西兰，没有法定的转让规则。出口商和数字服务提供商可以将所有外币收入保留在海外或当地外币账户中，无需遵守强制性的兑换时间表，也无需将出口收益按一定比例出售给本地市场。

央行监管: 新西兰储备银行（Te Pūtea Matua）

离岸数字新锐银行 / EMI 白名单

Stripe 适配度: High

离岸金融科技电子货币机构在法律上并不被禁止支持新西兰企业，但它们并非主要的资金结算渠道。新西兰不颁发英国式的电子货币机构许可证，大多数外国电子货币机构必须与持牌本地银行合作，或依赖交易性银行服务来获得新西兰元结算能力。对于进行跨境SaaS收费的企业出口商来说，离岸电子货币机构可以作为辅助的收款和支付渠道，尤其适用于多币种支付和低费用交易结算。然而，由于声誉风险、缺乏完整的新西兰银行许可保护、资本验证能力有限，以及为满足法定和流动性需求而需要维持国内银行关系，将其作为主要运营账户的使用效果属于中等到低水平。谨慎的做法是将主要的新西兰元运营账户放在一级银行中，而仅将受监管的国际电子货币机构用于诸如Stripe/Billing或Paddle等辅助计费流程。

第8栏 / 第8a行 董事声明并证明，该申报在所有重大方面均为真实且准确。 这是一份个人签字的电子认证文件。如果某董事在签署IR4文件时明知海外订阅者的收入被遗漏、离岸关联方发票为虚假，或转让价格被操纵以从新西兰扣除利润，那么根据1994年税务管理法第143A条，该董事将面临民事赔偿罚款和刑事起诉的处罚。非居民董事并不因其外国居住身份而得到保护；对于属于新西兰公司的收入而言，新西兰的刑事和执法管辖权适用于他们，而且禁止离境命令可以阻止他们在税务债务或调查尚未解决时离开新西兰。 IR4申报时间过晚会导致延迟申报罚款（对于企业而言，初始法定延迟申报罚款为250新西兰元，若税款仍未支付，还会产生额外的延迟缴纳罚款）；未支付的税款将按照规定利率计算利息，并在到期日之后增加1%的延迟缴纳罚款；七天后再增加4%，持续违约则每月增加1%。民事方面的罚款范围从因未采取合理措施或选择不可接受的税务策略而面临的20%罚款，到采用滥用税收手段时面临的100%罚款，以及逃避税或类似行为时面临的150%罚款。如果故意提交虚假申报表以逃税，则可能面临刑事起诉，个人可能被处以高达50,000新西兰元的罚款和5年监禁；对于刑事欺诈行为，没有最低金额限制——触发刑事犯罪的标准是欺诈行为及故意隐瞒行为。

转让定价与经济实质

主文档/本地文档门槛: 新西兰并未对所有关联方交易设定统一的法定最低限额标准；不过，税务局的转让定价合规框架要求对重要的跨境关联方交易进行同步记录，并要求对于大型跨国企业而言，需建立本地文件/主文件体系。对于合并收入至少为13亿新西兰元的集团来说，必须遵守CbCR规定。实际上，年度价值超过约1000万新西兰元的关联方交易被视为重要交易，但缺乏明确阈值并不意味着无需根据1994年税收管理法保持公平定价证明及IRD记录。

经济实质审查范围: 新西兰没有实施加勒比地区/英属维尔京群岛那种经济实体法规，但经济实体特征体现在公司注册地规定、永久机构门槛标准、转让定价原则、2007年所得税法BG1/GA1章中的反规避规则以及反空壳原则中。对于无代码网站构建器和低代码平台提供商而言，产品开发、合同执行、用户数据管理、定价、风险管理和收入结算等核心收入生成活动必须由位于新西兰的员工和资产来完成，只有这样，该新西兰公司才能被视为真正的收益受益人。如果外国母公司或新加坡/香港/英属维尔京群岛的关联企业负责执行这些核心收入生成活动，而新西兰实体只是向订阅者开具发票，那么国内税务局可以将利润重新分配给那些拥有重要经济活动和职能的实体，或者因为新西兰实体只是一个没有实际商业目的的空壳公司而拒绝其条约福利。

致命合规红线与董事个人责任

逃税 / 隐瞒境外数字收入

法定制裁: 1994年税收管理法第141A条和143A条：对于民事逃税行为，处以逃税金额的150%作为罚款，此外还需支付资金使用利息；对于公司官员或董事的逃税行为，可处以最高50,000新西兰元的罚款和/或最多5年的监禁；税务局局长还可以根据最佳信息进行默认评估，此时税务债务即可立即收回。

董事个人责任: 公司的伪装因欺诈和逃避行为而被打破：如果董事故意隐瞒收入，根据1994年税收管理法中的董事责任规定，该董事需对由此产生的税收不足和罚款承担个人责任；法院可依据1993年公司法第301条命令公司返还资产；税务局可根据税务法第157条提出禁止出境命令，从而将该董事从航空旅行中排除，直到其税收债务得到偿还为止；若被判有罪，该董事还可能被取消董事资格，其海外资产也将通过互助条约被追踪。
转移定价操纵 / 向境外知识产权所有者转移 royalty（特许权使用费）

法定制裁: 《2007年所得税法》第GC13条授权国内收入署长确定公平价格并调整新西兰公司的应税收入；根据《1994年税务管理法》，对于不可接受的税务状况或滥用转移定价行为，相应的罚款可高达20%至100%，在严重情况下，针对调整金额的专门转移定价罚款可达40%；资金使用的利息则从原定到期日开始计算。

董事个人责任: 签署转让定价文件或在董事会会议记录中虚假描述不存在的职能、资产或风险的董事，可能被认定参与了误导性税务行为；若公司资不抵债，该董事可能就未支付的税款调整承担个人责任；法院可根据《1993年公司法》规定，责令该董事返还通过交易隐瞒或虚假补偿方式提取的不合理特许权使用费；可对其实施旅行限制并追究虚假陈述的法律责任，严重行为可能导致最高五年有期徒刑。
虚假空壳公司 / 避免滥用税收协定和经济实质的避税行为

法定制裁: 《2007年所得税法》第BG1条和第GA1条中的一般反避税规定允许税务局重新评估该安排并对其经济实质进行征税；该公司可以被视为非居民企业，或被视为在别处拥有常设机构。从而剥夺了条约带来的利益，使所有来自新西兰的费用按照法定费率受NRWT约束；这种滥用税收政策的处罚为差额金额的100%，如果以逃税为目的使用壳结构，则面临150%的罚款以及刑事起诉。向支付处理机构或税务机关作出虚假声明，也构成第143A条规定的刑事欺诈行为。

董事个人责任: 如果一家公司只是个幌子或假象，新西兰法院会揭开公司的面纱，让其负责人直接承担所欠税款的责任；董事则面临民事资产返还的处罚。根据1993年《公司法》第301条，对于故意参与隐蔽交易的行为，可采取恢复措施和赔偿措施；根据第383条，相关人员可能被取消资格；破产管理人可将通过壳公司支付的费用视为无效交易予以追回。国内税收局可使用第157条关于禁止离境的命令，将某董事列入黑名单，禁止其离开新西兰，直至其未缴税款得到偿还。而滥用企业名义进行欺诈行为则构成犯罪，需承担最高5年的监禁处罚，此外还须被没收犯罪所得。
