公司设立证书 新西兰公司注册局 根据海牙认证公约成员国的规定：仅需取得注册官认证的副本，并提交给新西兰内部事务部（DIA）办理认证，无需进行领事认证。对于非海牙认证成员国：需取得注册官认证的副本，先提交给内部事务部（DIA）进行认证，再提交给外交、贸易与对外关系部（MFAT）进行认证，最后提交至目的地国的领事馆或大使馆办理领事认证。海牙认证途径与领事认证途径相互排斥，二者不可串联使用。 Validity ~90 days

董事会首期决议范本 (Pro-Forma First Board Resolution)
[公司名称]有限公司董事会第一届会议的决议，根据1993年公司法第8条及第1项条款作为正式会议记录予以通过。所有签署人作为公司董事，特此放弃召开董事会会议的通知义务，同意执行以下业务交易，并确认这些决议自注册证书签发后立即生效。  
1. 注册地址。决议确定公司的注册地址应位于注册申请中指定的街道地址，且该地址在营业时间内对股东及相关机构具有可访问性；公司秘书或董事应将注册地址报送给公司注册处，并根据第31条规定及时通知任何变更情况。  
2. 股份资本的认购与分配。决议确定公司的初始法定股本应划分为登记册上所记载数量的普通股，每股无面值；认购人应根据股份分配决议中的约定，以现金或财产形式支付对价以认购这些股份。董事获授权出具股票证书、发行股票凭证、在股份登记册中登记股东姓名，并采取一切必要措施以确保合法和实益所有权的有效登记。  
3. 银行授权。决议确定公司应在银行授权文件中指定的银行开立企业交易账户及托管结算账户，且该银行应收到这些决议的认证副本，并获得不可撤销的授权，以兑现所有支票、借记指令、电子资金转账、SWIFT电汇、电文指示、托管释放确认书以及包含两位授权签名或总经理传真签名的外汇合同，但需遵守银行的合规政策。  
4. 法定官员任命。决议确定注册申请中指定的自然人董事将被任命为总经理和法定合规官员；如果董事会决定，还可以任命一名公司秘书，其有权维护法定登记册、提交年度报告以及履行1993年公司法规定的所有通知义务。如果没有公司秘书，则由董事共同承担法定记录保存职责。  
5. 一般条款。决议确定两名董事或一名总经理可以代表

外汇管制与央行政策诊断

经常项目兑换自由度

新西兰元可以在经常账户和资本账户交易中自由兑换。对于资本流入、利润汇回、股息支付或股东贷款偿还而言，不存在普遍的外汇管制限制。支付给非居民股东的股息需缴纳15%的新西兰非居民预扣税，或按适用较低条约税率缴纳。根据《海外投资法》，如果资本账户投资涉及敏感土地、捕鱼配额或重大商业资产，则可能需要进行审查；而普通的半导体批发贸易投资则无需事先批准。对于交易利润或资本收益的汇款，也无需中央银行授权。

出口外汇强制结汇要求

新西兰不对出口收益设定法定上交要求。没有强制性的归国时间限制，也没有强制性的货币兑换为新西兰元的要求。出口商可以保留外币收据，按照市场汇率自由兑换，或将其存放在海外账户中。出口交易仍需遵守反洗钱/反恐怖融资的记录与报告要求，但储备银行并不要求必须上交外汇收益。

股息预提税 (WHT)

新西兰法律规定的国内税率：根据2007年所得税法第N部分，新西兰公司向非居民支付股息时，税率为30%。不过，如果公司设有预提积分账户，则向非居民支付的“完全预提”股息的实际税率为28% NRWT。预提积分部分不受NRWT限制；现金股息被视为已预提部分，适用30%的NRWT税率。但预提积分可以抵消公司税，因此完全预提股息的股东税负总和为28%。对于条约国家而言，双边协定通常将NRWT降低至15%（或对于持有10%或以上股份的符合条件的企业股东，为5%，具体取决于双边协定规定）。

转让定价与经济实质

主文档/本地文档门槛: 新西兰转移定价文件提交标准（自2022年7月1日起生效）：如果跨国集团的综合集团收入至少为1亿新西兰元，且该新西兰实体或集团在该年度内的跨境关联方交易金额超过5000万新西兰元，则必须提交“主文件”。如果集团的全球收入达到1亿新西兰元或以上，且该新西兰实体在该年度内的跨境关联方交易金额超过1000万新西兰元，则必须提交“本地文件”。对于低于这些标准的企业，虽然不需要同时提交相关文件，但强烈建议提交此类文件，这样可以降低或消除处罚风险。在为期4年的重新评估期间，“重要企业”的标准为：全球收入达1亿新西兰元，且与新西兰的关联方交易金额达1000万新西兰元。

经济实质审查范围: 新西兰没有独立的“经济实质规定”体系，但2007年《所得税法》包含一项全面的反避税规则（第BG 1条），以及针对CFC和转让定价的具体规定。这些规定实际上要求条约索赔和损失利用必须具备真正的经济实质。从事SSD/CPU芯片经纪业务的批发贸易公司必须在新西兰具备实质性的运营实体：如物理办公室或仓库、参与采购和销售的员工、承担库存风险的责任，以及履行管理和决策职能。若未能满足这些条件，则可能被根据“经济实质原则”重新认定其税务身份，被剥夺税务居民权益，并可能面临国际税务机构规定的处罚。

致命合规红线与董事个人责任

逃税 / 欺诈意图

法定制裁: 根据1994年税务管理法第143A条，逃避纳税或类似行为对公司而言可处以高达50,000新西兰元罚款；根据第143B条，欺诈性逃避纳税行为对个人则可能导致最高5年的监禁。国内税务局还规定，对于被逃避的税款，可处以150%的罚款（第141D条），并可能对欺诈行为处以最高8年的监禁。

董事个人责任: 明知参与或授权逃避义务的董事，可被追究个人刑事责任，最高可被判处五年监禁。该董事还可能就民事罚款承担连带责任，若公司实为空壳公司，法院可穿透公司法人地位。法院还可发出旅行禁令，并责令退还未缴税款。
转让定价 / 利润转移

法定制裁: 国内税务局可以调整纳税人的收入，以反映市场正常价格（见GC 6-14 ITA 2007）。如果纳税人有逃避税收的明显目的，则可能会面临高达税收缺口100%的惩罚（见141E条）。对于信息披露不充分的转让定价案件，适用8年的重新评估期限。

董事个人责任: 签署错误转让定价文件或参与被撤销方案的董事，若为明知参与者，可能需承担罚款等个人责任。该董事可能面临被取消资格、旅行禁令，若该安排构成刑事逃税，则可能被判处监禁。
空壳公司 / 缺乏经济实质

法定制裁: 《一般避免规则》可使该安排无效，而国内税务局可将收入重新归属于实际经济所有者。根据1993年《公司法》，不从事业务的公司可被注销。如果公司并非“实际所有人”或缺乏任何实际业务目的，则相关协议可能被拒绝执行。

董事个人责任: 空壳公司的董事可能因使公司违反《公司法》而被追究个人责任（如reckless trading，第135条），若其签署虚假报表，还可能被追究税务犯罪责任。他们可能被禁止担任董事职务，并面临监禁处罚。
跨境贸易中的反洗钱/反恐融资不合规问题

法定制裁: 根据2009年反洗钱/反恐融资法，法人实体的民事罚款可达20万新西兰元，个人的民事罚款可达2万美元。故意违反规定将面临最高两年监禁和每起案件最高3万美元的罚款。金融市场监管局是非银行行业的监管机构。

董事个人责任: 董事及高级管理人员可能因违反反洗钱/反恐融资规定而承担个人责任。法规规定，对报告实体的“高级管理人员”施加个人责任。若董事明知允许公司为被制裁人员处理资金或未进行反洗钱审查，可能面临被禁止从事相关业务及监禁。
虚假开票 / 伪造文件

法定制裁: 根据1994年税收管理法，逃避纳税的处罚为差额金额的150%；对于虚假的 GST申报行为，因严重疏忽可处以50%的罚款，而滥用税务手段则处以100%的罚款。伪造行为根据1961年犯罪法也可构成刑事犯罪，可能面临最高10年的监禁。

董事个人责任: 涉及开具虚假发票的董事将承担刑事责任，可能被处以罚款并判处监禁。根据刑事追偿法规，可追查并冻结该董事的资产。此外，该董事还可能被法院裁定在一定期限内不得担任公司董事或经理职务。
未按规定进行注册及缴付增值税

法定制裁: 延迟注册处罚：如果行为属于欺诈行为，将立即处以未缴纳 GST金额的75%的罚款；否则，将处以5%的罚款以及每月递增1%的利息。税务部门可以按完整的应税供应价值征收GST，如果某人故意不注册以进行欺诈行为，则可能被起诉。

董事个人责任: 董事在公司未支付GST且董事未采取合理措施确保支付的情况下，可能需就未缴GST承担个人责任，依据《1994年税务管理法》第11A部分的董事处罚制度。该处罚为未缴GST金额的100%加利息，且可直接追索董事个人责任，无需适用公司法人的保护屏障。
