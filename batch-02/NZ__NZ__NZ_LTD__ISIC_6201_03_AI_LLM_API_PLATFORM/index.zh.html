跨境出口 0% 零税率申报条件

根据1985年商品和服务税法，某些商品可享受零税率待遇。对于商品而言，当这些商品由供应商出口或交付给非居民并在法定时间内从新西兰出口时，即可享受零税率。对于包括 AI/LLM 推理 API 订阅和基于令牌的数字平台服务在内的各种服务，当这些服务提供给在提供时位于新西兰境外的非居民接收方，且这些服务并非用于在新西兰境内直接使用或消费时，则适用零费率政策。如果供应商拥有足够的文件证明接收方为非居民且未使用新西兰服务，那么提供给海外GST注册企业的远程服务也可以享受零税率。而提供给新西兰居民客户的服务则仍需缴纳15%的GST。

新西兰没有实行实时财政清算、持续交易控制或数字反欺诈标记制度。已注册 GST的供应商必须出具符合规定的GST发票，并根据营业额和注册偏好，以每月、每两个月或每六个月的周期通过myIR以电子方式提交GST申报表。电子发票开具是自愿性的，可通过Peppol网络进行；国内税务局可以通过电子数据捕获或信息请求获取交易记录，但并没有强制性的API标记要求。

国内税务局可以对零税率出口商品进行审计，并追溯征收GST以及使用资金利息。如果出口商或服务供应商无法证明接收方的非居民身份、商品的实际出口情况，或者服务并未在新西兰被使用，那么就会面临民事罚款。对于由此产生的GST不足情况，罚款标准如下：缺乏合理注意或处于不可接受的税务状况时，罚款为20%；极度疏忽时，罚款为40%；滥用税收时，罚款为100%；而逃避税行为则处以150%的罚款。利息则从原本应适用的出口税到期日开始计算，即如果这些商品没有享受零税率的话。新西兰没有法定的外汇回流期限；180天的时间限制仅作为证据保留和审计审查的参考标准，而非法律上的回流要求。

外汇管制与央行政策诊断

经常项目兑换自由度

新西兰实行完全自由化的资本和经常账户可兑换机制。不存在外汇管制，对资本流入或流出也没有中央银行的审批要求，对利润、股息、特许权使用费或资本的回流也没有任何限制。新西兰元具有自由浮动特性，在全球市场上活跃交易。居民与非居民实体可以在国内及国外持有外币银行账户，无需事先批准。出口收入无需上交，企业也不需按照任何法定时间将外币收入转换为新西兰元。唯一的相关义务来自《2009年反洗钱和打击恐怖主义融资法》，该法律要求银行对客户进行尽职调查并报告可疑交易。对于由全球客户盈利的持牌AI/LLM API平台而言，美元、欧元或其他结算货币转化为新西兰元的操作费用及后续股息分配完全不受限制。从监管角度来看，只要相关交易具有商业合理性、有完整记录且符合公司注册业务目的，利润汇出则不存在障碍。银行仍可以对加密货币等高风险支付来源进行内部合规审查，但这属于KYC范畴，而非法定外汇管制限制。

出口外汇强制结汇要求

新西兰没有规定的外汇收入交存期限，也没有强制性的兑换比例要求。出口商可以将所有外汇收入保留在境外账户中，或按照商业银行的汇率自由兑换，但需遵守银行内部政策和反洗钱/反恐怖融资记录要求。

转让定价与经济实质

主文档/本地文档门槛: 新西兰没有像OECD国家那样设定明确的本地货币门槛（NZD），要求必须进行本地文件/主文件准备工作。不过，如果跨境关联方交易的价值超过100万新西兰元用于购买，或100万新西兰元用于销售（对于贷款来说，如果贷款金额超过500万新西兰元），则税务管理部门要求必须准备并保存转移定价文档。实际上，任何重要的关联方交易都必须以公平交易的方式进行记录。

经济实质审查范围: 新西兰没有像阿联酋那样有正式的独立经济实体法规，但CFC和一般反规避规则要求新西兰公司必须拥有真正的经济实体。在OECD BEPS行动8-10的框架下，以及有限风险实体分析中，都适用核心收入生成活动原则。对于人工智能LLM API平台而言，该公司必须证明其在新西兰拥有重要的运营职能（管理、开发和风险控制），以证明其利润的合理性，并防止利润转移至或来自相关的海外实体。如果该安排具有逃税性质，国内税务局可以根据2007年所得税法第BG 1条重新认定相关交易。

致命合规红线与董事个人责任

逃税及虚假低报

法定制裁: 《1994年税务管理法》第143A条和第143B条：逃避纳税的处罚为所逃税款的150%；个人可能被处以高达50,000新西兰元的罚款，公司则可能被处以100,000新西兰元的罚款；根据第143A(2)(g)条和第146条，董事或高管可能被处以最多5年的监禁。

董事个人责任: 根据1993年《公司法》第135条，在公司资不抵债时允许进行交易或从事逃税行为的董事可能需对公司债务承担个人责任。根据2009年《刑事收益（追回）法》，法院可以下令进行民事资产返还。根据1994年税收管理法第157条，如果税务债务仍未偿还，则可能被禁止出境。可能面临最高5年的监禁。
转让定价操纵与资本弱化

法定制裁: 《2007年所得税法》第GC 6至GC 14条（转让定价调整）及第GC 15条（薄资本化）规定，不得扣除多余的利息，因此需缴纳28%的额外所得税，此外还需支付资金使用利息，若存在疏忽或不合理的税务行为，还须缴纳40%的罚款或100%的罚款。

董事个人责任: 明知在税务申报中提供虚假转让定价信息的董事，将依据1994年《税务管理法》第148条承担个人罚款责任。若公司为代理人或空壳公司，法院可根据1993年《公司法》穿透公司法人面纱，且董事可能根据第383条被禁止管理公司长达五年。
反洗钱及空壳公司不合规

法定制裁: 2009年反洗钱和反恐融资法（AML/CFT）规定，对个人每违反客户尽职调查或记录保存要求，处以最高不超过20万新西兰元的民事罚款；对法人实体每违反上述要求，处以最高不超过200万新西兰元的民事罚款；同时，根据1961年《犯罪法》第243至245条，对洗钱行为处以刑事处罚，最高可判处七年监禁。

董事个人责任: 如果董事明知地允许公司被用于洗钱或恐怖融资，其将对反洗钱/反恐融资合规义务承担个人责任。金融市场监管局或中央银行可对董事发出金钱罚单。法院可下令没收资产并实施旅行禁令。此外，根据《公司法》建立的以经合组织为基础的“全球透明度”制度，要求董事信息必须公开披露，因此董事不能依赖代理人的保密安排。
