法定设立与首期章程 (Statutory Formation)

主管官方机构、法典依据、验资锁资规程与首期董事会决议范本。

官方主管注册局

新西兰企业局是商业、创新与就业部的一个职能部门，负责管理新西兰企业注册系统，该系统可通过 www.companiesoffice.govt.nz 和 register.companiesoffice.govt.nz 访问，用户需通过 RealMe身份服务进行认证。

现行法典依据

1993年公司法（1993年第105号公共法令），经修订。核心条款：第10至16条（公司的注册及法律地位）、第12至13条（申请及注册处的公司设立义务）、第20至24条（公司名称规则）、第31至34条（公司章程）、第124至126条（股份的发行与分配）、第151至153条（董事的资格、人数及同意事项）、第189条（注册办事处），以及第366至372条（费用与执行措施）。经修订的《公司费用条例》规定了公司设立费用。

法定设立章程文件

电子公司设立申请通常称为《NZCN表》（“申请注册公司”），依据1993年公司法第12(1)条提交，最终根据该法第15条颁发法定的公司设立证书（CIR表）。

法定实缴资本与验资锁资账户流程 强制验资锁定

没有法定的最低实收资本要求。新西兰法律不设定资本下限、不要求设立托管存款，也不要求提供银行担保；根据第124-126条，股份可以以全额支付或部分支付的方式，按照认购方协商的代价发行，非居民持有股份则不受限制。

董事会首期决议范本 (Pro-Forma First Board Resolution)
公司名称有限公司（“公司”）——首次董事会决议（全体书面一致决议）。根据1993年《公司法》第137条，董事们一致决议如下：  
1. 股份认购：接受各认购人提交的股份认购申请；按照公司首次股份注册簿所列明的股份类别及数量，分配并发行已全额缴付或部分缴付的股份，缴付价格按所定金额执行；任何未缴付的资本，由董事会决定后予以追缴。  
2. 注册办事处：公司注册办事处设立于向注册署提交的物理地址，该地址位于新西兰境内且可实际访问，且服务地址的维护应符合1993年《公司法》第189条的规定。  
3. 董事任命：任命以下人员为董事，自其根据第153条提交同意书之日起生效：[董事姓名]；并任命[总经理姓名]为总经理及主要执行负责人，授权其开设银行账户并签署合同。  
4. 登记册：设立股东、董事及担保登记册，并将公司记录的保管职责交由总经理负责。  
5. 董事们将采取一切必要措施，办理新西兰商业编号及税务局注册手续。

根据1986年商品与服务税法第11(1)条，若供应商在供应商品后的28天内将其出口（经税务局因合理原因可延长，包括在船舶上或处于海关监管下时可延长至60天），则该出口商品适用零税率；商品在新西兰境内不得进行供应。根据该法第11A条，若服务提供给非居民，且服务未与新西兰土地或商品相关联，且供应商能够提供充分的文件证明服务接收方为非居民，则该服务适用零税率。对于逆向物流业务（ISIC 5229 / NAICS 488510），若进口退回商品的品质评级和翻新服务是为海外客户提供的，且退回商品将被重新出口，且服务接收方为非居民且未注册商品与服务税的实体，则该服务适用零税率；合规要求包括充分的退货管理协议（RMA）记录、海关出口文件以及海外结算的证明文件。

新西兰并不要求实时财政结算、持续交易控制或数字印章机制。电子发票支付是可选的，商业、创新与就业部及税务局通过认可的Peppol接入点，推动B2G领域使用Peppol BIS 3.0标准进行交易互操作性。注册了GST的供应商必须出具符合要求的税务发票，该发票应包含供应商的税务局编号、发票日期、供应商及收件人的姓名和地址、商品/服务的描述及数量、不含GST的价格、GST金额以及GST税率；在特定条件下，买方自制的税务发票和信用票据也是被允许的。数字税务发票是被认可的，相关记录必须在接到要求时以电子形式提供给国内收入署官员。

外汇管制与央行政策诊断

经常项目兑换自由度

新西兰没有法定的外汇管制制度。新西兰元可以在当前账户和资本账户交易中完全兑换使用。对于向非居民汇款股息、特许权使用费、贷款还款、利润或清算收益并无限制。唯一的相关法规是2005年《海外投资法》，该法律适用于涉及特定阈值以上的敏感土地和重要商业资产的交易；普通的跨境逆向物流、贸易、仓储和配送业务则无需获得海外投资办公室的批准。银行操作仍需经过反洗钱/反恐怖融资验证、FATCA/CRS报告要求以及标准交易目的声明，但无需遵守任何外汇管制规定。

出口外汇强制结汇要求

没有。自外汇管制被取消后，新西兰就不再实施强制性的出口收入上缴规定。出口收入无需汇回本国，也无需兑换成新西兰元或存入指定的新西兰账户。新西兰的逆向物流公司可以合法地将外币存放在海外或新西兰的外币账户中作为营运资金。该公司必须保留完整的会计和税务记录，包括收入确认情况、出口服务和商品的零税率 GST处理情况以及企业所得税情况，但无需遵守上缴期限或兑换比例要求。

转让定价与经济实质

主文档/本地文档门槛: 如果某年度总收入低于3000万新西兰元，新西兰居民无需提供转移定价文件。但如果总收入超过3000万新西兰元，且当年与跨境相关方进行的交易总价值超过500万新西兰元，则必须准备本地文件。当跨国集团的合并年度收入超过10亿新西兰元时，则必须准备主文件。

经济实质审查范围: 新西兰没有像阿联酋那样独立的经济实质法规。相反，经济实质是通过判例法和《2007年所得税法》中的一般反规避规则来实施的，这些规定将缺乏商业实质的安排重新定性为其他形式。对于损失结转的“业务连续性测试”以及针对非居民拥有的种子公司征税的“额外法定优惠”，都要求存在真实的新西兰管理职能。如果一家公司在新西兰没有办公室、员工或明确的决策机制，根据双边协议中的决胜规则，该公司可能被认定为非居民；或者，这种规避行为将被认定为违法，并面临高达税收缺口100%的罚款。

致命合规红线与董事个人责任

逃税

法定制裁: 民事税务逃漏罚金为逃税金额的150%（1994年税收法案第141E条）；根据1994年税收法案第143B条提起刑事诉讼，最高可处以新 Zealand 纪元20万元罚款及最多五年监禁。

董事个人责任: 签署或明知协助提交虚假财务报表的董事，可能需承担罚款并被责令赔偿。法院可在案件解决前实施旅行禁令，严重案件可依据1993年公司法对董事处以禁止任职的处罚。
转移定价操纵

法定制裁: 税务局可将收入重新分配至新西兰公司，进行重新评估，并处以净差额罚款，罚款比例为40%（不可接受的解释）或100%（滥用税法行为）。利息按日累计。

董事个人责任: 批准反映虚假转让定价的税务虚假陈述的董事，可能根据1994年《税务法案》第149B条被个人追缴短缺罚款。此外，他们还可能被禁止管理公司长达五年，并在税务债务超过一定门槛时被禁止离开新西兰。
空壳公司滥用 / 缺乏经济实质

法定制裁: 税务局可取消GAAR下的税收优惠，并根据双边税收协定（DTA）将公司视为非居民。最高可处以税款短缺额100%的罚款。公司注册处可因公司未开展业务而注销该公司。

董事个人责任: 如果董事允许公司在无力清偿债务的情况下继续营业，他们可能需就未缴的公司税承担个人责任（《1993年公司法》第135条）。民事诉讼可冻结董事的个人资产，且董事在获得法院许可前可能被禁止离开新西兰。
反向物流中的欺诈 / 反洗钱

法定制裁: 根据1961年《犯罪法》，通过欺诈手段获取税收退款可处以最高7年的监禁。根据《税务管理法》对逃税行为的处罚为差额金额的150%。如果该实体提供金融服务，则适用《反洗钱/反恐怖融资法》，公司可能面临高达200万新西兰元的罚款。

董事个人责任: 亲自参与欺诈计划的董事可能被认定为犯罪行为的共犯。民事欺诈诉讼可能导致赔偿损失及惩罚性赔偿。可能限制其出境，且可就税务欺诈申请引渡。
