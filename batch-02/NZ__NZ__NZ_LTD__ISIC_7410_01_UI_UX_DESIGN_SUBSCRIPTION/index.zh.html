外汇管制自由度 新西兰实行一种基本自由化的外汇制度，新西兰元具备完全的经常账户和资本账户可兑换性。在接收、保留或汇回外币方面，不存在外汇管制审批、数量限制或必须交给托管机构的要求。包括股权注入、公司间贷款、股息汇回、利润支付、贷款偿还以及与贸易相关的结算等在内的资本流入和流出，都可以通过任何注册商业银行进行自由操作。非居民股东可以拥有新西兰有限公司，无需受到外汇管制的限制，只要相关业务不涉及敏感土地或重要的商业资产，且不违反《2005年海外投资法》的规定。新西兰储备银行作为中央银行和审慎监管机构，负责监督银行和支付系统，而非行使外汇审批职能。因此，目前对可兑换性的实际限制并非法定外汇管制，而是银行层面的反洗钱/反恐怖融资审查、制裁筛查、资金来源验证，以及公司在分配资金时需遵守新西兰居民和非居民预扣税规定。一旦企业完成了公司办公室的注册手续、缴纳了税款，并且银行对受益所有权进行了经济实质核查后，向股东支付利润就是合法且无限制的。对于支付路由、远期对冲、外币账户或多币种余额等事项，则不需要中央银行的特别许可，这使得新西兰的司法管辖区非常适合用于国际式设计即服务财务结构。

董事会首期决议范本 (Pro-Forma First Board Resolution)
新西兰有限公司首届董事会决议

本首届董事会决议系于公司成立之日作出，并载入新西兰有限公司首届董事会会议的会议记录。该公司系根据新西兰《1993年公司法》注册成立。

决议如下：

1. 股份资本与认购。董事会确认，创始股东已承诺认购公司全部初始发行的普通股，每股无面值，根据新西兰法律，公司无需设立最低实收股本。董事会决议接受该认购，并依据股东认购记录分配上述股份，将认购金额及分配日期登记于股份名册，并在相关方要求时，签发相应的股份证书或电子记录。

2. 以服务形式发行股份。董事会确认，根据《1993年公司法》第41条，公司发行的股份可依法以现金或非现金形式支付，为避免疑义，设计即服务（Design-as-a-Service）数字订阅业务无需强制设立托管账户或资本冻结。

3. 银行账户。董事会授权董事开设并维持公司所需之银行及支付账户，包括在注册于新西兰的银行开设账户，以及使用Stripe_Billing和Wise等支付渠道。董事会批准采用银行授权机制，即任何两名董事或其他指定签署人可签署支票或电子指令。秘书应将本决议的正式副本提交至任何银行或支付机构。

4. 注册办事处。董事会确认公司注册地址，声明该地址为公司接收法律文书的地址，并指示董事及秘书在地址发生变更时，按规定的表格通知注册机构。

5. 法定职务人员。董事会任命所列人员担任公司董事，如公司章程规定，亦任命一名秘书或其他职务人员。上述人员均已同意履职，并根据《1993年公司法》第151至153条的规定履行职务。

6. 税务与授权。董事会授权董事及秘书向新西兰税务局申请公司税务识别号（IRD）、增值税（GST）注册以及任何必要的“按所得缴税”（PAYE）义务，并向公司注册处提交所有法定申报文件。

7. 生效条款。本决议自即日起生效，可作为第三方依据，对本决议所述行为具有完全授权效力。

本决议由董事长签署，并载入公司董事会会议纪要册。

外汇管制与央行政策诊断

经常项目兑换自由度

新西兰实行一种基本自由化的外汇制度，新西兰元具备完全的经常账户和资本账户可兑换性。在接收、保留或汇回外币方面，不存在外汇管制审批、数量限制或必须交给托管机构的要求。包括股权注入、公司间贷款、股息汇回、利润支付、贷款偿还以及与贸易相关的结算等在内的资本流入和流出，都可以通过任何注册商业银行进行自由操作。非居民股东可以拥有新西兰有限公司，无需受到外汇管制的限制，只要相关业务不涉及敏感土地或重要的商业资产，且不违反《2005年海外投资法》的规定。新西兰储备银行作为中央银行和审慎监管机构，负责监督银行和支付系统，而非行使外汇审批职能。因此，目前对可兑换性的实际限制并非法定外汇管制，而是银行层面的反洗钱/反恐怖融资审查、制裁筛查、资金来源验证，以及公司在分配资金时需遵守新西兰居民和非居民预扣税规定。一旦企业完成了公司办公室的注册手续、缴纳了税款，并且银行对受益所有权进行了经济实质核查后，向股东支付利润就是合法且无限制的。对于支付路由、远期对冲、外币账户或多币种余额等事项，则不需要中央银行的特别许可，这使得新西兰的司法管辖区非常适合用于国际式设计即服务财务结构。

出口外汇强制结汇要求

新西兰没有关于法定出口收益上交规定的规定。出口商或设计订阅供应商可以将所有外币收入保留在境内或关联的外币账户中，可以以自由市场价格立即兑换为新西兰元，或者将资金存放在海外而不进行兑换。新西兰储备银行没有强制性的转换比例，也没有规定退出的时间限制。

股息预提税 (WHT)

根据新西兰法律，如果新西兰公司向非居民支付的股息完全符合新西兰的税收抵扣规定，则需缴纳15%的NRWT；如果股息未完全符合这些规定，则需缴纳30%的NRWT。在全资集团内部支付的股息，只有在满足特定行政条件的情况下，才能根据补充股息规则免缴NRWT。在大多数新西兰双边协议中，投资组合股东所享有的条约股息率为15%，而对于持有至少10-15%投票权的企业股东，该比率可降至5%，但需符合利益限制或主要目的测试。

转让定价与经济实质

主文档/本地文档门槛: 年度跨境关联方交易金额为1,000,000新西兰元（每个交易类别或总关联方交易金额超过此数额时，需提交本地文件）。对于年合并收入超过680,000,000新西兰元的跨国集团，根据OECD BEPS行动13模板，还需提交主文件及按国家划分的报告。新西兰转让定价规则还要求提供同步文档，通常需在申报日期后30天内或税务处理完成前准备完毕。

经济实质审查范围: 新西兰并不实施海湾模式下的经济实体法规，但实体因素在三个领域具有重要的法律意义：(1) 税务居民身份——在新西兰注册的公司属于居民企业，除非其管理中心位于其他地方；而由海外机构管理的新西兰公司则可能被视为非居民企业，具体取决于相关条约条款；(2) 永久机构——新西兰的设计机构的外国母公司不得通过员工或附属机构在新西兰设立需缴纳税的永久机构；(3) 双边税收协定权益——新西兰实体必须是设计知识产权的实际所有者，并且必须在新西兰开展核心收入生成活动，包括战略设计决策、客户合同签订、风险承担以及订阅业务的高级管理。那些仅持有设计订阅合同、而所有实质性活动都在海外进行的壳公司新西兰有限公司，在税务方面将被忽略，其利润将依据OECD BEPS规则进行重新分配。

致命合规红线与董事个人责任

通过虚假实体和人为利润提取进行逃税

法定制裁: 《2007年所得税法》第BG 1条和第GB 1条允许国内税收部门重新审查交易情况，并忽略该虚假公司。 《1994年税务管理法》第141A-141EB条规定，对于滥用税收行为，处以100%的罚款；对于逃税行为，则处以150%的罚款，此外还需支付资金使用利息。根据《1961年犯罪法》第144A条，逃避纳税评估的人可被判3年以下监禁；根据第144B条，逃避纳税支付则可被判7年以下监禁。

董事个人责任: 当公司成为逃税的掩护时，公司的面纱就会被打破。那些签署虚假服务协议或指挥利润转移的董事，因获得了利益或积极参与，需对由此产生的税收缺口承担共同责任。税务局可以发出禁止离境命令，冻结其离开新西兰的权利，并根据《2009年犯罪收益（追回）法》实施民事资产追回措施。根据《1993年公司法》，董事还可能被取消管理公司的资格，处罚期长达10年，且因欺诈行为可能面临刑事监禁。
转让定价操纵及未提供同期资料

法定制裁: 《2007年所得税法》第GC 6条至第GC 18条要求税务专员将应税收入调整为公平合理的金额。若未能提供相应的转让定价文件，公司将面临20%的疏忽罚款；对于严重疏忽行为，罚款幅度为40%；而对于滥用税收政策的行为，则处以100%的罚款。《1994年税务管理法》还规定，若未能披露跨境交易信息，公司将需提交各国报告；未提交此类报告则每次违规将被处以1,000美元的罚款，且每逾期一个月还将面临额外罚款。

董事个人责任: 若董事明知地批准了非独立交易的集团内部交易价格，且公司仅作为资金通道使用，且转让定价调整金额超出公司实际支付能力，则该董事须就差额罚款承担个人责任。董事可能被禁止参与新西兰公司的管理，其个人银行账户可能面临民事禁令，若该安排涉及虚假发票或故意误导税务机关，则将依据1961年《犯罪法》追究其刑事责任。在董事在支付调整后的税款之前已将公司资产剥离的情况下，可适用“揭开公司面纱”原则。
虚假的双边税收协定申请、空壳公司处理及NRWT不符合规定

法定制裁: 国内税务局将依据OECD MLI主要目的测试原则以及国内反避税规则，拒绝给予DTA相关优惠。该公司需对全部股息按法定30%（若完全推算则按15%）缴纳NRWT税款，此外还需支付因税务违规行为而产生的100%罚款及资金使用利息。根据1994年税收管理法，任何未能从股息或利息支付中代扣NRWT的公司，都将面临与未缴NRWT金额相当的绝对责任罚款，税务机关有权直接从董事个人处追回该罚款，因为他们应对公司的债务负责。

董事个人责任: 明知税收协定主张虚假而安排股息支付的董事，须就未缴税款及罚款承担个人责任。该董事可能被税务局依据离境禁止令制度列入黑名单，并被从公司注册处董事名册中移除。若股息支付至关联离岸实体后又转分给董事，民事资产追索可延伸至该董事的个人财产。刑事起诉可能导致最高七年监禁，以及巨额赔偿令。
