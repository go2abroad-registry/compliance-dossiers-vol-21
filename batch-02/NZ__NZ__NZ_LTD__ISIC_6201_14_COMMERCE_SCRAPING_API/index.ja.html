Master / Local File threshold: 収入年度におけるニュージーランドドル500万ドル以上の国際的な関連会社取引については、移転価格に関する義務的なドキュメント（ローカルファイル）を提出する必要がある。年間統合売上高がニュージーランドドル11.25億ドル以上を達成するグループには、マスターファイルおよび国別レポートの作成が義務付けられている。これらの水準を下回っても、ニュージーランドの納税者は、APIサブスクリプション、データライセンス、ホスティングサービス、および内部会社間管理費用に関して、公正価格（公正取引）を証明するための同時記録を保持しなければならない。

Fatal Compliance Red Lines & Director Liability

税務规避および虚偽の空壳会社

Statutory sanction: 2007年所得税法のBG1条は、税回避行為を無視している。GC1～GC20条に定められた移転価格規則では、公正な利益配分が求められる。1994年税務行政法の141(2C)条では、不正な税務処理による100％の罰金が科される。また、143条では、故意の逃税行為に対して50,000ニュージーランドドルまでの刑事罰金や5年以下の懲役が科される。

Director personal liability: 1993年会社法第189条によれば、会社が詐欺や脱税のために利用されている場合、裁判所は会社の面を切り破ることができる。取締役は、未払い税金の民事的返還に加えて、利息や罰金についても共同して責任を負う。内国税局は、債務が解決されるまで取締役がニュージーランドを離れることを禁じる旅行禁止命令を発行することができる。また、刑事判決により取締役は会社の経営を停止され、StripeアカウントやUSDCウォレットに保管されている資産が没収されることもある。
源泉徴収税の回避と不正なDTA救済

Statutory sanction: NRWTは、2007年所得税法のRF 8条およびRF 9条に基づいて課されるものであり、納税者はRNA 8条に従って支払う必要があります。控除を怠ると、ニュージーランド企業はNRWTの全額と、1994年税務行政法に基づく150％の違反罰金、および遅延支払い罰金が科されます。不正な条約申請を行うことは、最大5年の懲役および最大50,000ニュージーランドドルの罰金が科される犯罪です。

Director personal liability: NRWTの支払いを故意に指示した取締役は、未納の外国の控除税について個人的に責任を負う。民事的な措置には、個人の課税、米国ドル資産の差し押さえ、税額不足の返還が含まれる。刑事責任には、刑罰、出国禁止、取締役の資格喪失、および虚偽の条約主張によって得た利益の没収が含まれる。
反洗錢違反およびデジタル決済の匿名化

Statutory sanction: 2009年の反マネーロンダリングおよびテロ資金調達対策法では、法人に対して最大200万ニュージーランドドルまでの民事罰が科される。また、取締役や上級管理者も最大30万ニュージーランドドルまでの個別の民事罰を受ける可能性がある。AML/CFT報告機関として登録しないことは継続的な違反行為となる。もし拡散された資金が犯罪財産である場合、1961年犯罪法第243条～245条に基づくマネーロンダリングに関する起訴により、最大7年の懲役刑が科される。

Director personal liability: 故意または重大な過失でAML違反を助長した取締役は、民事罰および洗錢資金の返還に個人的に責任を負うことができる。会社法1993年第189条に基づき、会社が金融犯罪の手段として使用された場合、会社の盾（企業の法的分離）が貫かれる可能性がある。取締役は、洗錢に関わる場合、旅行制限、デジタル資産の没収、最多5年間の取締役資格の取消し、および刑罰にさらされる可能性がある。
