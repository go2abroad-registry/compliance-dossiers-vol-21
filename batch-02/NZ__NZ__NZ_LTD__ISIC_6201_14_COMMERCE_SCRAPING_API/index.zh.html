商业开户与资金池

商业开户与外汇资金池

央行经常项目外汇管制诊断、本土商业大行与离岸数字EMI矩阵、拒单痛点防御指南。

外汇管制自由度 新西兰实行完全开放的资本账户和经常账户制度。新西兰元具有自由兑换性，交易不受外汇管制限制。新西兰储备银行无需对跨境股权注入、贸易收入、股息汇回或贷款偿还进行审批。金融市场管理局和储备银行对持牌机构进行监管，但不会实施外汇交还或兑换限制。银行可根据《2009年反洗钱和打击恐怖主义融资法》进行个人交易审查、制裁筛查以及税务信息交换规定，但这些措施并不会阻碍合法的资金流动。向非居民股东分配股息需缴纳非居民预扣税或经批准的发行方征税，但资金可以以客户选择的货币进行汇出。缺乏外汇管制以及没有官方汇率区间，使得多货币资金管理操作能够保持稳定。企业可以持有外币账户，使用任何被允许的货币进行交易，并通过交易商对冲货币风险，无需获得中央银行的许可。唯一的实际障碍在于银行入网文件、实际所有权披露以及常规商业KYC要求，这些都可以通过适当的法律实体记录来满足。总体而言，其兑换性可视为无限制且符合全球标准下的低合规要求。

法定注册代理人与物理地址 强制持牌代理

《1993年公司法》规定，注册办事处必须是新西兰境内的实际物理地址，对公众开放，并可接受文件送达；仅使用邮政信箱不构成注册办事处。若存在独立的实体新西兰商业地址，可将虚拟办公室或商业信箱仅作为服务地址使用，但须向注册署和内政税局披露该地址。对于ISIC 6201类（网络数据抓取和代理API服务）的企业，新西兰本地银行通常会拒绝仅使用邮政信箱开设账户，而要求董事亲自到场或提供本地办公地址。内政税局也将将境外控制的虚拟办公室视为缺乏税收居民身份的弱证据，可能将收入重新归类为在境外管理所得，因此，若该企业希望获得新西兰公司身份及税收协定保护，使用虚拟办公室在商业上并不可行。

外汇管制与央行政策诊断

经常项目兑换自由度

新西兰实行完全开放的资本账户和经常账户制度。新西兰元具有自由兑换性，交易不受外汇管制限制。新西兰储备银行无需对跨境股权注入、贸易收入、股息汇回或贷款偿还进行审批。金融市场管理局和储备银行对持牌机构进行监管，但不会实施外汇交还或兑换限制。银行可根据《2009年反洗钱和打击恐怖主义融资法》进行个人交易审查、制裁筛查以及税务信息交换规定，但这些措施并不会阻碍合法的资金流动。向非居民股东分配股息需缴纳非居民预扣税或经批准的发行方征税，但资金可以以客户选择的货币进行汇出。缺乏外汇管制以及没有官方汇率区间，使得多货币资金管理操作能够保持稳定。企业可以持有外币账户，使用任何被允许的货币进行交易，并通过交易商对冲货币风险，无需获得中央银行的许可。唯一的实际障碍在于银行入网文件、实际所有权披露以及常规商业KYC要求，这些都可以通过适当的法律实体记录来满足。总体而言，其兑换性可视为无限制且符合全球标准下的低合规要求。

出口外汇强制结汇要求

在新西兰，没有法定的转让要求或固定的兑换比例。所有出口商可以将全部出口收入保留在获得许可的外币账户中，或按市场汇率兑换为新西兰元。新西兰储备银行并不规定回国的具体时间限制。不过，出口商仍需保存准确的发票和税务记录，以便向国内税务局提交。新西兰统计局可能会对相关数据进行抽样统计；如果要求提供数据，那也仅限于数据收集而已，并非一种控制或审批机制。因此，目标实体的以美元或欧元支付的API订阅费用可以通过Stripe或直接电汇方式收取，无需遵守任何强制性的外汇转换规定。

转让定价与经济实质

主文档/本地文档门槛: 在应税年度内，任何跨境关联交易金额达到或超过新西兰元500万的，均需提交强制性的转让定价文档（本地文件）。年合并收入达到或超过新西兰元11.25亿的新西兰企业集团，须编制主文件和各国报告。即使未达到上述门槛，新西兰纳税人也必须保留同期记录，以证明其在API订阅、数据许可、托管服务以及集团内部管理费用方面的定价符合独立交易原则。

经济实质审查范围: 新西兰没有实施类似加勒比地区的“经济实体法规”制度；相反，企业实体资格是通过《2007年所得税法》中的一般反规避规则、商业测试规定、双重税收协定下的永久机构认定机制以及新西兰来源地规则来确定的。那些虽然拥有网络抓取API收入的权利，但在新西兰却没有核心收入生成活动——如董事会会议、员工操作、客户合同签订以及中央风险管理等——的企业，将被视为一个中介机构：利润将重新分配给实际履行相关职能的司法管辖区；可能拒绝给予相应的抵扣优惠；对向离岸主体支付的款项还将征收NRWT税。

逃税与空壳公司

法定制裁: 《2007年所得税法》第BG 1条未考虑税务规避行为；《GC 1-GC 20条中的转让定价规则》要求按照公平交易原则进行利润分配。《1994年税务管理法》第141(2C)条对故意逃避纳税行为处以100%的罚款，而第143条则规定对故意逃税行为可处以高达50,000新西兰元的罚款或5年以下的监禁。

董事个人责任: 根据1993年《公司法》第189条，如果公司被用于欺诈或逃税行为，法院可以揭开公司的法人面纱。董事们需共同承担返还未缴税款以及利息和罚款的民事责任。国内税务局可以下达旅行禁令令，禁止董事离开新西兰，直到债务得到清偿为止；而刑事定罪则会使该董事失去管理公司的资格，并导致存储在 Stripe 账户或 USDC 钱包中的资产被没收。
逃税行为及滥用双边支付协议优惠措施

法定制裁: 根据2007年所得税法第RF 8条和第RF 9条，须缴纳NRWT；支付方须依据第RNA 8条履行此项义务。若未进行扣除，新西兰公司将被处以全额NRWT，此外还需根据1994年税务管理法支付150%的逃避税罚款以及延迟付款罚金。虚假申报条约则属于犯罪行为，可判处最高5年的监禁，并处以最高50,000新西兰元的罚款。

董事个人责任: 明知指示未缴纳外国预提税的董事，须就未缴纳税款承担个人责任。民事救济措施包括对个人进行税务评估、扣押美元资产以及追回税款差额。刑事责任包括监禁、禁止出境、董事资格取消以及因虚假税收协定主张而获得的利益没收。
反洗钱违规与数字支付匿名化

法定制裁: 《2009年反洗钱和打击恐怖主义融资法》规定，对法人机构违反该法律的行为可处以最高200万新西兰元的民事处罚；董事或高级管理人员则可能面临最高30万新西兰元的个人民事处罚。未注册为反洗钱/打击恐怖主义融资报告实体则属于持续违法行为。如果所传播的资金属于犯罪所得，根据《1961年犯罪法》第243-245条，可因洗钱行为被起诉，并面临最高7年的监禁。

董事个人责任: 任何明知或轻率促成反洗钱违规的董事，可能需承担民事罚款及追缴洗钱资金的个人责任。根据1993年公司法第189条，若公司被用作金融犯罪的工具，可穿透公司法人面纱。该董事可能面临旅行禁令、数字资产被查封、最多五年内被禁止担任董事职务，以及因洗钱行为被判处刑事监禁。
