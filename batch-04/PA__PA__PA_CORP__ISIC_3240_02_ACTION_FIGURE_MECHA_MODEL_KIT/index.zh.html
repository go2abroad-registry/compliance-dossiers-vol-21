法定设立与首期章程 (Statutory Formation)

主管官方机构、法典依据、验资锁资规程与首期董事会决议范本。

官方主管注册局

巴拿马公共登记处——商业登记部，总部位于巴拿马城，各省设有分支机构；登记文件可通过巴拿马公共登记处的在线服务门户提交。

现行法典依据

巴拿马共和国1927年第32号法律《公司总法》，经2018年第5号法律《私人机构注册与治理现代化》及2018年第70号法律《受益权持有声明制度》修订，再加上2016年第52号法律中的居民代理人要求规定。

法定设立章程文件

法定实缴资本与验资锁资账户流程 免验资锁资账户

公司章程中必须声明注册资本不低于10,000美元（1927年第32号法律，第1条）。公司设立时无需设立法定保证金或强制性一次性付款；认购人可作出合格声明，表明其认购的资本已全部缴付，而登记机构无需核实实际银行存款。外国股东可持有100%已发行股份。

注资与解冻路径: 巴拿马共和国英勇消防队颁发的消防安全检查证书，涵盖疏散通道、灭火器、自动喷淋系统覆盖以及塑料树脂的防火储存；由市政工程局及经认证的专业工程师出具的结构荷载和电气安全检查证书；根据劳动与劳动发展部（MITRADEL）要求完成的 workplaces 职业健康与安全登记及审批，包括机器防护、噪声控制、个人防护装备（PPE）、热应激管理以及应急预案。

实缴资本规则: 公司章程中必须声明注册资本不低于10,000美元（1927年第32号法律，第1条）。公司设立时无需设立法定保证金或强制性一次性付款；认购人可作出合格声明，表明其认购的资本已全部缴付，而登记机构无需核实实际银行存款。外国股东可持有100%已发行股份。

董事会首期决议范本 (Pro-Forma First Board Resolution)
决定：公司同意创始股东认购一百（100）股普通股，该认购行为被视为已完全支付。进一步决定：公司的注册办事处应设在[常驻代理名称]的办公地点，该人被任命为巴拿马法律文件的送达常驻代理人。进一步决定：[主席姓名]、[秘书姓名]和[财务主管姓名]分别被任命为主席、秘书和财务主管，任期均为一年。进一步决定：主席和财务主管共同有权开设银行账户，签订生产、供应和许可合同，并在正常业务过程中在文件上加盖公司印章。
工业与物理准入/环评许可 (EIA) Mandatory Environmental Clearance

贸易与工业部（MICI）——工业标准与技术总局（DGNTI-COPANIT）负责强制性玩具安全技术规范制定；工厂区市政当局负责工业运营许可审批。

类别: 《市政工业运营许可证》（制造行业市政运营许可），同时需持有DGNTI-COPANIT玩具安全认证证书（遵循ISO 8124系列和ASTM F963标准），这是生产及销售机甲模型套件的前提条件。

对于巴拿马 S.A. 企业来说，没有选择勾选选项或直接转嫁选举的选项；默认情况下，S.A. 属于企业级企业纳税人，但可以选择按照特殊跨国公司总部制度、知识城制度或巴拿马太平洋特别经济区制度来运营。这些制度都提供专门的税收减免和注册程序，同时普通运营仍然完全受地域来源规则约束。

流转税 (VAT / GST) 与出口 0% 零税率

标准增值税/流转税率

7%

强制登记营业额门槛 (Nexus)

在巴拿马销售商品或服务所获得的年度应税总收入为36,000美元；新企业需在运营第一年实现的应税营业额超过此阈值后才能注册，但小型贡献制企业则享有可选的简化注册制度，其总收入可高达36,000美元。

跨境出口 0% 零税率申报条件

零百分比的ITBMS税率适用于：(i)根据海关出口声明从巴拿马实际出口的商品；以及(ii)完全在巴拿马境外、提供给非居民或根据DGI规定属于“出口服务”的服务，前提是供应商为巴拿马注册企业，且服务是在国外提供的；卖方必须始终保留出口证明、从巴拿马出境的运输证明，对于服务业务而言，还需保留与非居民接收方的合同以及证明来自外国的付款的银行记录。

  • 海关出口申报（出口申报 / DEX）
  • 提单或空运提单，或其他证明货物已离开巴拿马领土的国际运输单据
  • 汇入证明 / 外国银行信贷证明，证明出口款项已在法定汇回期限内汇入巴拿马

根据第201-5429号决议，巴拿马要求通过DGI的“电子发票系统（SFE）”进行电子发票开具。每份发票必须由DGI认可的计费软件或在线平台生成，并以XML格式在实时或接近实时状态下通过授权API渠道提交给DGI，同时需包含标准的“QR”验证代码；预先打印的税务发票仅可在获得DGI的“税务打印许可”后使用，且必须通过“发票管理”系统进行报告。数字发票无需使用实体税务印章，但必须拥有由DGI验证的唯一发票单。

DGI可以追溯审查出口零税率申请；如果无法提供真实的出口证明、外国银行确认文件或180天内归还的凭证，则会导致零税率被取消，需按7%的ITBMS利率外加附加利息来计算，同时还需缴纳相当于逃税金额的100%的罚款；而欺诈性或虚假的出口行为则会根据巴拿马刑法规定面临刑事税务欺诈处罚，且出口商的ITBMS注册资格将被DGI规定的期限内取消。

外汇管制与央行政策诊断

经常项目兑换自由度

巴拿马实行完全以美元为结算货币的开放货币制度，没有外汇管制。资本交易和经常账户交易均可自由兑换，对利润汇出、股息分配或海外企业资金回流也没有任何法定限制。只要交易符合反洗钱报告标准，进行外汇操作无需事先获得巴拿马中央银行的许可。

出口外汇强制结汇要求

巴拿马没有强制要求将出口收入上交的规定，也没有法定的兑换比例，也不对持有外币出口收入设定时间限制。出口商可以将收入保留为美元或任何其他可兑换货币，并可以自由用于国内或跨境结算。

央行监管: 巴拿马没有独立的中央银行；银行业和信托行业由巴拿马银行管理局负责监管。该国的货币体系以美元作为法定货币，并使用自由流通的巴波亚硬币。

离岸数字新锐银行 / EMI 白名单

Cross-border EMI / Fintech rails 适配度: High

对于巴拿马公司而言，离岸数字电子货币机构的上线审批等级为“中等至高”，但存在严格的结构性限制。巴拿马银行局并不允许独立的电子货币机构作为银行进行运营，但受监管的非银行金融机构以及获得许可的电子货币/信托运营商可以提供虚拟IBAN服务。跨境电子货币账户可用于交易结算，但银行局要求必须进行严格的反洗钱/客户身份识别验证，并且企业需有合法的本地注册关系。未经许可的外国电子货币机构无法独立开设账户，除非有国际银行协议或互惠银行安排。

转让定价与经济实质

主文档/本地文档门槛: 巴拿马比索（PAB）：当纳税人年度总营业额达到或超过PAB 1,000,000，或与关联方的交易总额达到或超过PAB 250,000时，必须准备本地文件和主文件。

经济实质审查范围: 巴拿马经济实体要求适用于那些从银行、融资、租赁、分销、服务中心以及知识产权等相关活动中获得收入的企业。而动作模型套件的金属注塑制造则不属于此类相关活动；不过，DGI和金融实体监督机构可以在没有实际场所、没有人力资源、没有制造设备且在巴拿马没有实际经济风险的情况下，将非居民拥有的公司重新定义为空壳企业。

致命合规红线与董事个人责任

逃税

法定制裁: 监禁二至五年，罚款金额为逃避税额的两倍，年利率为10%的滞纳金，以及取消纳税人于DGI活跃纳税人名录中的注册资格。

董事个人责任: 签署或明知导致提交虚假年度报告的董事，须就税款差额及任何非法转移利润的返还承担连带及分别责任，并将面临旅行禁令、资产冻结以及被禁止担任其他巴拿马公司的高级管理人员。
空壳公司 / 缺乏经济实质

法定制裁: 若存在相关活动，则处以最高75,000巴波亚的罚款，并责令该实体解散；对于不相关的活动，DGI将S.A.重新认定为巴拿马税务居民，对整体制造利润按25%的税率征税，并对所有被视为汇回国内的金额征收10%的补充股息预扣税。

董事个人责任: 当董事实际接收公司资金或故意签订没有实际经济内容的合同时，就会突破公司边界；每位董事需共同承担所有公司税、利息和罚款，并且可能在支付款项前面临个人旅行限制。
转移定价操纵

法定制裁: DGI可根据独立交易原则调整应税基础，对由此产生的25%税款差额进行征税，收取10%的年利率，并根据巴拿马财政法转让定价条款，对未申报的转让定价调整金额处以最高达100%的罚款。

董事个人责任: 批准或在董事会会议记录中包含非公允价格的董事，需就额外税款、利息及罚款承担个人责任；故意设计此类定价行为将被视为逃税，可能面临刑事起诉及民事赔偿。
洗钱 / 反洗钱

法定制裁: 违反巴拿马2015年第23号反洗钱/反恐怖融资法，该实体将面临最高1,000,000巴拿马比索的行政罚款、对责任人员最高8年监禁的刑事处罚、资金被没收，以及必须从公共登记系统中移除的处罚。

董事个人责任: 董事及合规官若明知存在警示信号或故意接收可疑资金而未报告，将承担个人刑事责任和民事责任；法院可对个人银行账户和护照实施冻结令，一旦被定罪，将面临监禁。
