Tax ID type & application path: Unternehmensniveau-Steuern. Eine eingeschränkte Gesellschaft aus Neuseeland ist als eigenständiger Steuerpflichtiger in Neuseeland ansässig und wird anhand des Unternehmensertragssteuersatzes von 28 % auf weltweiten Ertrag besteuert. Neuseelands Gesellschaften, die von nicht ansässigen Inhabern besessen sind, werden auf weltweiten Ertrag besteuert; ausländischer Ertrag kann unter bestimmten Umständen dem Regime für kontrollierte ausländische Unternehmen (CFC) oder ausländische Investitionsfonds (FIF) unterworfen sein. Neuseeland verfügt über ein hybrides Steuerfeld, das sowohl weltweiten als auch territorialen Aspekt umfasst: Ertrag aus dem Inland ist stets besteuert, während ausländischer Ertrag nur für Steuerpflichtige besteuert wird, es sei denn, es gilt eine entsprechende Ausnahme oder eine CFC-Attributionsregel. Es gibt keine besondere steuerfreie Zone oder Ausnahme für ausländische Finanzzentren, die speziell auf Hersteller medizinischer Geräte anwendbar wäre.
